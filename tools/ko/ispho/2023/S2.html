T2. 뮤온의 비정상 자기 모멘트 (Muon anomalous magnetic moment) — 풀이

A1. 상대론적 입자의 에너지는 운동량으로 다음과 같이 나타낼 수 있다.

$$E = \sqrt{p^2c^2 + m_\mu^2c^4},$$

그리고 속력은 다음과 같다.

$$v = \frac{c^2p}{E} = \frac{cp}{\sqrt{p^2 + m_\mu^2c^2}}.$$

따라서 속력 차이는

$$\Delta v = c - v = c\left(1 - \frac{p}{\sqrt{p^2 + m_\mu^2c^2}}\right) \approx \frac{1}{2}c\left(\frac{m_\mu c}{p}\right)^2 \approx 1.75\cdot 10^5~\mathrm{m/s}$$

주어진 수치에서는 근사식을 써도 되며, 정확한 값과는 넷째 자리에서만 차이가 난다.

A2. 앞 문항의 에너지 식을 이용한다. 주어진 수치에서는 극상대론적 입자에 대한 근사식 $E \approx pc$를 써도 된다.

$$E_k = \sqrt{p^2c^2 + m_\mu^2c^4} - m_\mu c^2 \approx 2.99~\mathrm{GeV}$$

A3. 상대론적 운동 방정식

$$\frac{d\vec p}{dt} = q\vec v\times\vec B = \frac{q}{\gamma m_\mu}\,\vec p\times\vec B$$

로부터 속도와 운동량의 크기가 일정함을 알 수 있다. 따라서 운동량은 다음과 같이 회전한다.

$$\frac{d\vec p}{dt} = \vec\omega_c\times\vec p,\qquad \vec\omega_c = -\frac{q\vec B}{\gamma m_\mu}.$$

여기서 $\omega_c$는 뮤온의 각속도이다. 주기는

$$T = \frac{2\pi}{\omega_c} = \frac{2\pi m_\mu\gamma}{qB} = 1.49\cdot 10^{-7}~\mathrm{s}$$

궤도 반지름은

$$R = \frac{vT}{2\pi} = \frac{\gamma m_\mu}{qB}\,v = \frac{\gamma m_\mu}{qB}\cdot\frac{pc^2}{E} = \frac{p}{qB} = 7.12~\mathrm{m}$$

A4. 상대론적 시간 지연 때문에 실험실 좌표계에서 뮤온의 수명은 $t = \gamma\tau$이다. 따라서 회전 수는

$$N = \frac{t}{T} = \gamma\tau\,\frac{qB}{2\pi m_\mu\gamma} = \frac{qB\tau}{2\pi m_\mu} = 431$$

A5. 자기장 속의 자기 쌍극자에 작용하는 돌림힘은 $\vec M = \vec\mu\times\vec B$이므로, 운동 방정식은

$$\frac{d\vec s}{dt} = \vec M = \vec\mu\times\vec B = g_\mu\frac{q}{2m_\mu}\,\vec s\times\vec B = -g_\mu\frac{q\vec B}{2m_\mu}\times\vec s$$

A6. 앞 문항으로부터 각속도는

$$\vec\omega = -g_\mu\frac{q\vec B}{2m_\mu}.$$

따라서 각속도의 $z$ 성분은

$$\omega_z = -g_\mu\frac{qB}{2m_\mu}$$

B1. 문제에 주어진 속도 덧셈 공식을 떠올리자. 이 경우 $v'_x = 0$(좌표계 $C$의 속도의 $x$ 성분)이므로 분모는 $1 + v'_xv_x/c^2 = 1$이다.

$$v_{Cx} = v_x,\qquad v_{Cy} = v'_y\sqrt{1 - v_x^2/c^2} = v'_y/\gamma$$

B2. 좌표계 $B$가 $A$에 대해 속도 $\vec v$로 움직이면, 좌표계 $A$는 $B$에 대해 속도 $-\vec v$로 움직인다. 따라서 좌표계 $C$에 대한 좌표계 $B$의 속도는 $-v'_y$이고, 좌표계 $B$에 대한 좌표계 $A$의 속도는 $-v_x$이다. 계수 $\gamma$는 속도 $v'_y$로 계산한다.

$$\gamma = \frac{1}{\sqrt{1 - v_y'^2/c^2}} \approx 1,$$

$v'_y$에 대해 1차 항까지만 계산하면 되기 때문이다. 좌표계 $A$와 $B$의 속도는 서로 수직이므로 속도 덧셈 공식의 분모는 1이다. 좌표계 $C$에 대한 좌표계 $A$의 속도는

$$v''_{Ax} = -v_x,\qquad v''_{Ay} = -v'_y$$

B3. 두 벡터 사이의 각은 벡터곱으로 계산할 수 있다(벡터곱의 크기는 $|\vec a\times\vec b| = |\vec a||\vec b|\sin\alpha$이고, $\alpha$는 두 벡터 사이의 각이다). $\vec e_x$, $\vec e_y$, $\vec e_z$를 각각 $x$, $y$, $z$ 방향의 단위 벡터라 하자. 벡터곱은

$$-\vec v^{\,\prime\prime}_A\times\vec v_C = (v_x\vec e_x + v'_y\vec e_y)\times\left(v_x\vec e_x + (v'_y/\gamma)\vec e_y\right) = v_xv'_y\left(\frac{1}{\gamma} - 1\right)\vec e_z.$$

두 벡터 모두 $xy$ 평면에 평행하므로 벡터곱은 $z$축과 나란하고, $z$ 성분이 양수이면 회전각이 양수이다. $v'_y$의 1차 항까지는 $|\vec v^{\,\prime\prime}_A| = |\vec v_C| = v_x$로 근사할 수 있으므로, 회전각은

$$\Delta\theta = \frac{1}{v_x^2}\,v_xv'_y\left(\frac{1}{\gamma} - 1\right) = -\frac{v'_y}{v_x}\left(1 - \frac{1}{\gamma}\right)$$

B4. 실험실 좌표계에서 시간 $dt$ 동안 입자의 속도는 $v_y = a_y\,dt$만큼 변한다. 처음 순간 입자의 동행 좌표계인 좌표계 $B$에서 이에 대응하는 속도는 $v'_y = \gamma v_y$이다. 이 결과는 B1로부터, 또는 속도 덧셈 공식으로부터 직접 얻을 수 있다(실험실 좌표계는 좌표계 $B$에 대해 속도 $-v_x$로 움직이고, 실험실 좌표계에 대한 입자의 속도는 $\vec v = (v_x, v_y)$이다).

$$v'_y = \frac{v_y\sqrt{1 - v_x^2/c^2}}{1 - v_x^2/c^2} = \frac{v_y}{\sqrt{1 - v_x^2/c^2}} = \gamma v_y.$$

따라서 회전각은

$$d\theta = -\frac{\gamma a_y\,dt}{v_x}\left(1 - \frac{1}{\gamma}\right),$$

각속도는

$$\omega_T = \frac{d\theta}{dt} = -\frac{a_y}{v_x}(\gamma - 1)$$

앞의 부호 규약에 따라, 양의 회전각은 각속도의 양의 $z$ 성분에 해당한다.

B5. 자기장 속의 운동 방정식

$$\frac{d\vec p}{dt} = m_\mu\frac{d(\gamma\vec v)}{dt} = q\vec v\times\vec B$$

로부터 가속도 성분을 구하면($\gamma$는 일정하다)

$$a_y = -\frac{qv_xB}{\gamma m_\mu},$$

따라서 각속도는

$$\omega_T = \frac{qB}{\gamma m_\mu}(\gamma - 1)$$

C1. 전체 세차 각속도는 자기장 속에서의 세차 각속도와 토머스 세차 각속도의 합이다.

$$\omega_s = \omega_z + \omega_T = -g_\mu\frac{qB}{2m_\mu} + \frac{qB}{\gamma m_\mu}(\gamma - 1)$$

C2. 뮤온의 운동량은 A3에서 구한 자기장 속 뮤온의 각속도 $\omega_c$로 회전하며, 그 $z$ 성분은

$$\omega_{cz} = -\frac{qB}{\gamma m_\mu}.$$

따라서 운동량에 대한 스핀의 각속도는 스핀과 운동량의 각속도의 차이다(모든 회전은 $z$축에 대한 회전이다).

$$\omega_a = \omega_s - \omega_c = -g_\mu\frac{qB}{2m_\mu} + \frac{qB}{\gamma m_\mu}(\gamma - 1) + \frac{qB}{\gamma m_\mu} = -g_\mu\frac{qB}{2m_\mu} + \frac{qB}{m_\mu}.$$

$g_\mu = 2(1 + a_\mu)$를 이용하면

$$\omega_a = -a_\mu\frac{qB}{m_\mu}$$

C3. 진동수와 각속도의 관계는 $f_a = \omega_a/2\pi$이므로

$$a_\mu = \frac{m_\mu\omega_a}{qB} = \frac{2\pi f_am_\mu}{qB} = 0.00117$$

스핀 세차의 방향이 주어지지 않았으므로 $a_\mu$의 부호는 결정할 수 없다. 실제로는 $a_\mu > 0$이다.
