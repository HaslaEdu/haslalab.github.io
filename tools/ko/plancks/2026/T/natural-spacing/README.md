# PLANCKS 2026 Korean spacing correction

The previous translation retained the English prose slots' horizontal widths.
That left large gaps between Korean text and native inline expressions.

This edition packs Korean text and whole native expressions using their actual
advances. Each ordinary boundary has zero or one normal word space. Original
point sizes and physical line baselines remain fixed. Display equations,
figures, image transforms and the table of contents page-number column remain
stationary. Fractions, radical bars, scripts and accents move together.

All 18 pages have current visual review hashes. The assembled PDF has exactly
the same rendered pixels and glyph geometry as those reviewed page proofs.
The source font programs and original encoded image streams are preserved.

The frozen authoring programs are the exact files used on the recorded build
machine; their absolute input paths are retained as provenance. Per-page raw
plans, effective plans, overrides, source scopes, audits and review records are
stored here with byte hashes. The publication contract checks these hashes and
rejects stale reviews, missing native glyphs, moved figures, collisions, font
shrinking and gaps larger than one ordinary word space.
