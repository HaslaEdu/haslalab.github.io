물시계는 물이 줄면 느려진다. 남은 물의 무게가 줄면 구멍을 밀어내는 압력도 줄기 때문이다. 그래서 고대의 물시계는 눈금을 위쪽에 촘촘히, 아래쪽에 성기게 새겨야 했다.

모래시계는 그렇지 않다. 같은 굵기의 구멍에 같은 부피를 담아도, 모래는 처음부터 끝까지 똑같은 속도로 떨어진다. 남은 양이 절반이든 십분의 일이든 상관하지 않는다. 알갱이 더미가 액체와 결정적으로 다른 성질을 하나 가지고 있기 때문인데, 그것이 무엇인지가 이 문제의 주제다.

널리 퍼진 설명은 「알갱이 더미에서는 깊이가 깊어져도 바닥 압력이 더 이상 커지지 않는다」는 것이다. 이 설명은 절반만 옳다. 이 문제에서는 그 절반이 어디까지 옳은지를 수치로 확인한 뒤, 등시성의 진짜 원인을 배출구 바로 위에서 찾는다.

### 모형

- 반지름 $R$인 연직 원통에, 지름 $d$인 균질한 구형 알갱이가 높이 $h_0$까지 채워져 있다. 바닥 중앙에는 지름 $D$인 원형 배출구가 있다.
- 알갱이 더미의 벌크 밀도는 $\rho_b = \varphi\rho_p$이고, 충전율 $\varphi$는 깊이에 무관하다.
- 깊이 $z$는 알갱이 더미의 자유표면에서 아래로 잰다. 알갱이 더미 안의 연직 응력 $\sigma_v(z)$와 벽면의 수평 응력 $\sigma_h$는 $\sigma_h = K\sigma_v$로 이어져 있다. $K$는 야센 계수라 하며 상수로 본다. 벽은 알갱이 더미를 마찰 응력 $\tau_w = \mu_w\sigma_h$로 위쪽으로 되받는다.
- 알갱이 사이의 공기는 무시한다. 알갱이는 건조하며 서로 붙지 않는다(단 D.4는 예외).
- 물시계에서 물은 비점성·비압축성이고, 구멍의 넓이 $a$는 원통의 단면적 $A$보다 훨씬 작다.

## Part A - 물시계는 왜 느려지는가 (1.2점)

액면 아래 깊이 $h$에 뚫린 작은 구멍에서 나오는 물의 속도는 토리첼리 정리에 따라 $v = \sqrt{2gh}$이다.

::: q A.1 0.5pt
단면적 $A$인 원통형 물시계의 바닥에 넓이 $a$인 구멍이 있다. 액면 높이 $h(t)$가 만족하는 미분방정식을 세우고, 초기 높이 $h_0$에서 물이 완전히 빠질 때까지 걸리는 시간 $T_w$를 $A$, $a$, $h_0$, $g$로 나타내어라.
:::

::: q A.2 0.3pt
표 1의 $R$, $D$, $h_0$를 그대로 쓰는 물시계에 대하여 $T_w$의 값을 구하여라.
:::

::: q A.3 0.4pt
물이 앞의 절반만큼 빠지는 데 걸리는 시간과 뒤의 절반이 빠지는 데 걸리는 시간의 비를 구하여라. 이 결과를 근거로, 유량이 어떤 조건을 만족해야 시계가 등시성을 갖는지 한 줄로 말하여라.
:::

## Part B - 야센 응력 포화 (3.3점)

이제 같은 원통에 물 대신 알갱이를 채운다. **Part B에서는 배출구를 마개로 막아 알갱이가 정지해 있는 상태만 다룬다.** 마개의 넓이는 바닥 넓이의 $1\,\%$이므로 무시한다. 알갱이 더미가 액체와 다른 첫 번째 점은, 수평 방향으로도 응력을 전달해서 그 일부를 벽에 넘긴다는 것이다.

::: q B.1 1.1pt
깊이 $z$와 $z+dz$ 사이의 얇은 층에 작용하는 연직 방향 힘의 평형을 세워, $\sigma_v(z)$가 만족하는 미분방정식을 유도하여라. 자유표면에서 $\sigma_v(0)=0$인 해를 구하고, 그 결과를 특성 길이 $\lambda$를 써서

$$\sigma_v(z) = \rho_b g\lambda\left(1 - e^{-z/\lambda}\right)$$

꼴로 나타낸 뒤 $\lambda$를 $R$, $\mu_w$, $K$로 표현하여라.
:::

::: q B.2 0.4pt
$\lambda$의 값과, 알갱이를 $h_0$까지 채웠을 때 바닥의 연직 응력 $\sigma_v(h_0)$의 값을 구하여라. 같은 깊이의 정수압과 견주면 몇 분의 일인가?
:::

::: q B.3 0.5pt
바닥이 실제로 떠받치는 힘과 알갱이 전체의 무게를 각각 구하고, 그 비를 백분율로 나타내어라. 나머지는 무엇이 떠받치는가?
:::

::: q B.4 0.6pt
바닥의 연직 응력이 포화값의 $95\,\%$ 이상이 되기 위한 조건을 $\lambda$로 나타내고, 그때의 높이를 구하여라. 뒤에서 보게 되듯 알갱이의 질량 유량은 시간에 대하여 일정하다. 이를 받아들이고, 전체 배출 시간 가운데 위 조건이 깨지는 시간의 비율을 구하여라. 야센 포화만으로 모래시계의 등시성을 설명할 수 있는가?
:::

::: q B.5 0.7pt
원통은 스탠드에 고정하고, 원통 벽에 닿지 않는 바닥판만 저울 위에 올려놓은 채 알갱이를 조금씩 부어 넣는다. 채운 높이가 $h$일 때 저울이 가리키는 겉보기 질량 $M_{\mathrm{app}}(h)$를 구하여라. $h$를 계속 늘리면 $M_{\mathrm{app}}$은 어떻게 되는가? 그 극한값을 구하고, 표 1의 $h_0$에서의 값이 B.3의 결과와 맞는지 확인하여라.
:::

## Part C - 자유낙하 아치와 Beverloo 법칙 (3.8점)

배출구 바로 위에서는 알갱이들이 서로 버티며 돔 모양의 아치를 이룬다. 아치 위쪽의 무게는 모두 아치를 통해 옆으로 흘러 벽으로 가고, 아치 아래의 알갱이에는 아무 응력도 걸리지 않는다. 따라서 아치 아래의 알갱이는 정지 상태에서 출발하여 자유낙하한다. 아치의 높이는 배출구 지름에 비례한다고 본다.

::: q C.1 1.0pt
위 모형에서 배출구를 지나는 알갱이의 속도가 $v \propto \sqrt{gD}$임을 보이고, 이어서 질량 유량이

$$Q_m \propto \rho_b\sqrt{g}\,D^{5/2}$$

임을 차원해석으로 유도하여라.
:::

::: q C.2 0.6pt
실제로는 배출구 가장자리에서 폭 $\sim d/2$만큼의 고리 영역으로는 알갱이가 지나가지 못한다. 이를 유효 배출 지름 $D - kd$로 나타내면 Beverloo 법칙

$$Q_m = C\rho_b\sqrt{g}\,(D-kd)^{5/2}$$

를 얻는다. 빈 고리 논증만으로는 $k \approx 1$이 나오는데, 이 논증은 $k$의 자릿수만 정해 줄 뿐이다. 이 문제에서는 표 1의 실측값 $k = 1.4$를 쓴다. 이 식이 모래시계의 등시성에 대하여 무엇을 말하는지 설명하여라.
:::

::: q C.3 0.6pt
$Q_m$의 값을 구하고, 원통에 담긴 알갱이의 전체 질량 $M$과 이 모래시계가 다 떨어지는 데 걸리는 시간 $T$를 구하여라.
:::

::: q C.4 0.4pt
C.3의 결과로부터 배출구에서의 평균 속도를 구하고, 이를 자유낙하로 되짚어 아치의 높이를 추정하여라. 그 값이 $D$와 견주어 타당한가?
:::

::: q C.5 0.5pt
배출구가 너무 좁으면 아치가 무너지지 않고 알갱이가 아예 막힌다. 실험적으로 막힘이 일어나지 않으려면 $D/d \gtrsim 6$이어야 한다 [4]. 이 조건이 요구하는 최소 배출구 지름을 구하고, 표 1의 값이 그보다 얼마나 여유가 있는지 백분율로 말하여라.
:::

::: q C.6 0.7pt
같은 모래시계에 지름이 두 배인 알갱이($d = 0.60\,\mathrm{mm}$)를 담으면 배출 시간이 어떻게 달라지는지 구하여라. 이어 C.5의 막힘 조건을 다시 확인하고, 이 모래시계가 실제로 작동하겠는지 판정하여라.
:::

## Part D - 정밀도의 한계 (1.7점)

::: q D.1 0.4pt
Beverloo 법칙에서 배출구 지름의 상대 오차가 배출 시간의 상대 오차로 얼마나 증폭되는지 식으로 나타내어라. 가공 공차가 $\Delta D = \pm 0.05\,\mathrm{mm}$일 때 $T$의 상대 오차와 절대 오차를 구하여라.
:::

::: q D.2 0.4pt
이 모래시계를 「3분 $\pm$ 1초」 규격으로 팔려면 배출구 지름을 얼마나 정밀하게 가공해야 하는지 구하여라.
:::

::: q D.3 0.4pt
자유표면이 배출구에 가까워져 남은 높이가 $2D$ 아래로 내려가면 아치 모형은 더 이상 성립하지 않는다. 이 구간이 전체 배출 시간에서 차지하는 비율을 구하여라.
:::

::: q D.4 0.5pt
습한 공기에서는 알갱이 사이에 물의 액체 다리가 생기고, 두 알갱이를 끌어당기는 힘은 $F_{\mathrm{cap}} \approx \pi\gamma d$이다. 이 힘과 알갱이 하나의 무게의 비를 $\gamma$, $\rho_p$, $g$, $d$로 나타내고 값을 구하여라. 모래시계를 반드시 밀봉하는 까닭을 말하여라.
:::
