## Part A - How fast are the ions ejected? (2.5 pt)

::: intro
Syllabus: mechanics (energy conservation, momentum) and electromagnetism (charged particles in a potential difference). No further concepts needed [1].
:::

::: q A.1 0.5pt
Exit speed of the ions.
:::

#### SOLUTION:

All the work done by the potential difference becomes kinetic energy, so $eU_d = \tfrac12 m_i v_i^2$ and

$$v_i = \sqrt{\frac{2eU_d}{m_i}} = \sqrt{\frac{2\times1.602\times10^{-19}\times300}{2.180\times10^{-25}}} = 2.10\times10^4\,\mathrm{m\,s^{-1}} = 21.0\,\mathrm{km\,s^{-1}}.$$

#### MARKING SCHEME:

::: marking
| $eU_d = \tfrac12 m_i v_i^2$ | 0.2 |
| $v_i = 21.0\,\mathrm{km\,s^{-1}}$ (20.5–21.5) | 0.3 |
:::

::: q A.2 0.7pt
Ion mass flow rate and thrust.
:::

#### SOLUTION:

The number of ions ejected per second is $I_i/e$, so the ion mass flow rate is

$$\dot m_i = \frac{m_i}{e} I_i = \frac{2.180\times10^{-25}}{1.602\times10^{-19}}\times3.50 = 4.76\times10^{-6}\,\mathrm{kg\,s^{-1}}.$$

The thrust is the momentum ejected per unit time:

$$F = \dot m_i v_i = 4.76\times10^{-6}\times2.10\times10^4 = 0.100\,\mathrm{N} = 100\,\mathrm{mN}.$$

#### MARKING SCHEME:

::: marking
| $\dot m_i = (m_i/e) I_i = 4.76\times10^{-6}\,\mathrm{kg\,s^{-1}}$ | 0.3 |
| $F = \dot m_i v_i$ | 0.2 |
| $F = 100\,\mathrm{mN}$ (95–105) | 0.2 |
:::

::: q A.3 0.3pt
Specific impulse.
:::

#### SOLUTION:

$$I_{sp} = \frac{v_i}{g_0} = \frac{2.10\times10^4}{9.81} = 2.14\times10^3\,\mathrm{s}.$$

Chemical propulsion gives about $300\,\mathrm{s}$, so this is roughly 7 times larger.

#### MARKING SCHEME:

::: marking
| $I_{sp} = v_i/g_0 = 2.14\times10^3\,\mathrm{s}$ (2.1–2.2$\times10^3$) | 0.3 |
:::

::: q A.4 0.5pt
Propellant utilization.
:::

#### SOLUTION:

If every atom of the supplied propellant were ionized once, the ion current would be

$$I_\mathrm{max} = \frac{e}{m_i}\dot m = \frac{1.602\times10^{-19}}{2.180\times10^{-25}}\times5.0\times10^{-6} = 3.67\,\mathrm{A}.$$

Hence

$$\eta_m = \frac{I_i}{I_\mathrm{max}} = \frac{3.50}{3.67} = 0.953 = 95.3\,\%.$$

#### MARKING SCHEME:

::: marking
| $I_\mathrm{max} = (e/m_i)\dot m = 3.67\,\mathrm{A}$ | 0.3 |
| $\eta_m = 95.3\,\%$ (93–97) | 0.2 |
:::

::: q A.5 0.5pt
Ion number density in the acceleration region.
:::

#### SOLUTION:

Since $w \ll R_c$, the cross-section of the annulus is

$$A_c = 2\pi R_c w = 2\pi\times0.0425\times0.0150 = 4.01\times10^{-3}\,\mathrm{m^2},$$

$$n_i = \frac{I_i}{eA_c v_i} = \frac{3.50}{1.602\times10^{-19}\times4.01\times10^{-3}\times2.10\times10^4} = 2.6\times10^{17}\,\mathrm{m^{-3}}.$$

This is about 4 times smaller than $n_e = 1.0\times10^{18}\,\mathrm{m^{-3}}$ in Table 1. The table value is the density in the ionization region, where the ions are just being created. The value found here is the density after the ions have been accelerated. In steady state the particle flux $n_i v A_c$ is conserved, so the density falls as the speed rises.

#### MARKING SCHEME:

::: marking
| $A_c = 2\pi R_c w = 4.01\times10^{-3}\,\mathrm{m^2}$ | 0.2 |
| $n_i = I_i/(eA_c v_i) = 2.6\times10^{17}\,\mathrm{m^{-3}}$ (2.3–2.9) | 0.2 |
| Density falls as acceleration raises the speed | 0.1 |
:::

## Part B - What the magnetic field does (3.2 pt)

::: intro
Syllabus: electromagnetism (Lorentz force, circular motion in a magnetic field) and mechanics. The $\mathbf{E}\times\mathbf{B}$ drift follows directly from force balance, so it is not introduced separately [1, 2].
:::

::: q B.1 0.8pt
Electron Larmor radius.
:::

#### SOLUTION:

$$v_{te} = \sqrt{\frac{2eT_e}{m_e}} = \sqrt{\frac{2\times1.602\times10^{-19}\times20.0}{9.109\times10^{-31}}} = 2.65\times10^6\,\mathrm{m\,s^{-1}},$$

$$r_{Le} = \frac{m_e v_{te}}{eB} = \frac{9.109\times10^{-31}\times2.65\times10^6}{1.602\times10^{-19}\times1.50\times10^{-2}} = 1.0\times10^{-3}\,\mathrm{m} = 1.0\,\mathrm{mm}.$$

Compared with the channel width, $w/r_{Le} = 15.0/1.0 = 15$. An electron completes many orbits before it can reach a wall. The electrons are firmly held by the magnetic field.

#### MARKING SCHEME:

::: marking
| $v_{te} = 2.65\times10^6\,\mathrm{m\,s^{-1}}$ | 0.3 |
| $r_{Le} = m_e v_{te}/(eB) = 1.0\,\mathrm{mm}$ (0.95–1.1) | 0.3 |
| $w/r_{Le} \approx 15$, electrons are magnetized | 0.2 |
:::

::: q B.2 0.5pt
Ion Larmor radius and the ordering of scales.
:::

#### SOLUTION:

$$r_{Li} = \frac{m_i v_i}{eB} = \frac{2.180\times10^{-25}\times2.10\times10^4}{1.602\times10^{-19}\times1.50\times10^{-2}} = 1.9\,\mathrm{m}, \qquad \frac{r_{Li}}{L} = 76.$$

Hence

$$r_{Le}\,(1\,\mathrm{mm}) \ll L\,(25\,\mathrm{mm}) \ll r_{Li}\,(1.9\,\mathrm{m}).$$

The same magnetic field traps the electrons completely and barely touches the ions, because their masses differ by a factor of $2.4\times10^5$. Owing to this asymmetry only the electrons are trapped, and they hold up the potential difference. The ions fall through that potential difference and are accelerated in a straight line. The whole working principle of the Hall thruster is contained in this one inequality.

#### MARKING SCHEME:

::: marking
| $r_{Li} = m_i v_i/(eB) = 1.9\,\mathrm{m}$ (1.8–2.0) | 0.2 |
| $r_{Li}/L = 76$ | 0.1 |
| $r_{Le} \ll L \ll r_{Li}$: electrons trapped, ions pass through | 0.2 |
:::

::: q B.3 0.6pt
$\mathbf{E}\times\mathbf{B}$ drift.
:::

#### SOLUTION:

The velocity $\mathbf{v}_d$ at which the net force on an electron vanishes satisfies

$$-e(\mathbf{E} + \mathbf{v}_d\times\mathbf{B}) = 0 \;\Longrightarrow\; \mathbf{v}_d = \frac{\mathbf{E}\times\mathbf{B}}{B^2}, \qquad v_d = \frac{E}{B}.$$

It is perpendicular to both $\mathbf{E}$ and $\mathbf{B}$, that is, azimuthal, and it does not depend on the sign of the charge. With $E = U_d/L = 300/0.0250 = 1.20\times10^4\,\mathrm{V\,m^{-1}}$,

$$v_d = \frac{1.20\times10^4}{1.50\times10^{-2}} = 8.0\times10^5\,\mathrm{m\,s^{-1}}.$$

#### MARKING SCHEME:

::: marking
| $-e(\mathbf{E} + \mathbf{v}_d\times\mathbf{B}) = 0$ | 0.3 |
| $\mathbf{v}_d = (\mathbf{E}\times\mathbf{B})/B^2$, azimuthal | 0.2 |
| $v_d = E/B = 8.0\times10^5\,\mathrm{m\,s^{-1}}$ | 0.1 |
:::

::: q B.4 1.3pt
Hall current, thrust and self-consistency of the model.
:::

#### SOLUTION:

An azimuthal current density $j_\theta$ in the radial field $B_r$ feels a force $\mathbf{j}\times\mathbf{B}$ per unit volume, directed along the axis. Integrating over the acceleration region,

$$F = \int j_\theta B\,dV = B\int j_\theta\,dV = B\,(2\pi R_c)\int j_\theta\,dA = I_H B\,(2\pi R_c),$$

where $I_H = \int j_\theta\,dA$ is the total azimuthal current through the cross-section $L\times w$. This force is equal and opposite to the force the plasma exerts on the magnetic field, that is, on the magnetic circuit and the thruster body. By Newton's third law it equals the thrust on the thruster. The thrust is transmitted by the Hall current pushing on the magnets, not by the ions pushing on a wall.

Hence

$$I_H = \frac{F}{B\,(2\pi R_c)} = \frac{0.100}{1.50\times10^{-2}\times0.267} = 25.0\,\mathrm{A}, \qquad \frac{I_H}{I_d} = \frac{25.0}{4.50} = 5.5.$$

The Hall current is 5.5 times the discharge current. The current circulating inside is much larger than the current flowing through the external circuit.

Working back from $I_H = n_e e v_d\,(Lw)$,

$$n_e = \frac{I_H}{e v_d L w} = \frac{25.0}{1.602\times10^{-19}\times8.0\times10^5\times2.50\times10^{-2}\times1.50\times10^{-2}} = 5.2\times10^{17}\,\mathrm{m^{-3}}.$$

This is half of the $1.0\times10^{18}\,\mathrm{m^{-3}}$ in Table 1, the same order of magnitude. It also agrees in direction with A.5, which found a lower density in the acceleration region than in the ionization region. The model is self-consistent.

#### MARKING SCHEME:

::: marking
| $F = \int j_\theta B\,dV = I_H B(2\pi R_c)$ | 0.5 |
| By Newton's third law this force equals the thrust | 0.2 |
| $I_H = F/[B(2\pi R_c)] = 25.0\,\mathrm{A}$ (24–26) | 0.3 |
| $I_H/I_d = 5.5$ | 0.1 |
| $n_e = I_H/(e v_d L w) = 5.2\times10^{17}\,\mathrm{m^{-3}}$, same order of magnitude | 0.2 |
:::

## Part C - Ionization and losses (2.0 pt)

::: intro
Syllabus: kinetic theory (mean free path) and energy balance. The ionization rate coefficient and the effective ionization cost are outside the syllabus and are given in the text [1, 4].
:::

::: q C.1 0.7pt
Ionization mean free path.
:::

#### SOLUTION:

$$\lambda_\mathrm{ion} = \frac{v_n}{n_e\langle\sigma v\rangle} = \frac{300}{1.0\times10^{18}\times2.0\times10^{-13}} = 1.5\times10^{-3}\,\mathrm{m} = 1.5\,\mathrm{mm}.$$

Compared with the acceleration length, $L/\lambda_\mathrm{ion} = 25.0/1.5 = 17$. A neutral atom meets on average 17 chances of ionization before it leaves the chamber, so the probability that it passes through un-ionized is only $e^{-17} \sim 10^{-8}$. This is why $\eta_m$ in A.4 was close to 1.

#### MARKING SCHEME:

::: marking
| $\lambda_\mathrm{ion} = v_n/(n_e\langle\sigma v\rangle) = 1.5\,\mathrm{mm}$ | 0.3 |
| $L/\lambda_\mathrm{ion} = 17$ | 0.2 |
| Escape probability is tiny, so $\eta_m \approx 1$ | 0.2 |
:::

::: q C.2 0.5pt
Fraction of the power spent on ionization.
:::

#### SOLUTION:

Ions are produced at a rate $I_i/e$ per second, each costing $\varepsilon$, so

$$P_\mathrm{ion} = \frac{I_i}{e}\varepsilon = I_i\times25\,\mathrm{V} = 3.50\times25 = 87.5\,\mathrm{W}.$$

The total discharge power is $P = U_d I_d = 300\times4.50 = 1350\,\mathrm{W}$, so

$$\frac{P_\mathrm{ion}}{P} = \frac{87.5}{1350} = 6.5\,\%.$$

Ionization is cheaper than one might expect. Each ion is accelerated through $300\,\mathrm{V}$ but costs only $25\,\mathrm{V}$ to create. A higher discharge voltage lowers the fraction further.

#### MARKING SCHEME:

::: marking
| $P_\mathrm{ion} = (I_i/e)\varepsilon = 87.5\,\mathrm{W}$ | 0.3 |
| $P_\mathrm{ion}/P = 6.5\,\%$ (6–7) | 0.2 |
:::

::: q C.3 0.8pt
Real performance with beam divergence and voltage utilization.
:::

#### SOLUTION:

With $U_\mathrm{eff} = 0.90\,U_d$ the speed is multiplied by $\sqrt{0.90}$, and since only the axial component contributes to the thrust there is a further factor $\cos\theta$:

$$F = \dot m_i v_i\sqrt{0.90}\,\cos 15^\circ = 0.100\times0.9487\times0.9659 = 9.16\times10^{-2}\,\mathrm{N} = 91.6\,\mathrm{mN},$$

$$\eta_a = \frac{F^2}{2\dot m P} = \frac{(9.16\times10^{-2})^2}{2\times5.0\times10^{-6}\times1350} = \frac{8.40\times10^{-3}}{1.35\times10^{-2}} = 0.622 = 62.2\,\%.$$

This is still above the measured $83\,\mathrm{mN}$ and $51\,\%$. Possible causes of the remaining gap are multiply charged ions such as Xe$^{2+}$ (they carry less mass for the same current), ions and energy lost in collisions with the channel walls, and the power drawn by the magnet circuit and the neutralizer.

#### MARKING SCHEME:

::: marking
| $F = \dot m_i v_i\sqrt{0.90}\cos\theta$ | 0.3 |
| $F = 91.6\,\mathrm{mN}$ (89–94) | 0.2 |
| $\eta_a = 62.2\,\%$ (60–65) | 0.2 |
| At least one of: multiply charged ions, wall losses, auxiliary power | 0.1 |
:::

## Part D - Buy mass or buy time? (2.3 pt)

::: intro
Syllabus: mechanics (variable-mass systems, rocket equation) and thermal radiation and energy balance. No further concepts needed [1].
:::

::: q D.1 0.8pt
$\Delta v$ and comparison of propellant with chemical propulsion.
:::

#### SOLUTION:

$$\Delta v = v_i\ln\frac{m_0}{m_0 - m_p} = 2.10\times10^4\times\ln\frac{500}{450} = 2.21\times10^3\,\mathrm{m\,s^{-1}}.$$

To obtain the same $\Delta v$ with exhaust speed $v_\mathrm{ch}$,

$$m_f = m_0 e^{-\Delta v/v_\mathrm{ch}} = 500\,e^{-0.737} = 239\,\mathrm{kg} \;\Longrightarrow\; m_{p,\mathrm{ch}} = 500 - 239 = 261\,\mathrm{kg},$$

$$\frac{m_{p,\mathrm{ch}}}{m_p} = \frac{261}{50} = 5.2.$$

The exhaust speed is 7 times larger, so the exponent is 7 times smaller, and the propellant mass drops by more than a factor of 5.

#### MARKING SCHEME:

::: marking
| $\Delta v = v_i\ln[m_0/(m_0 - m_p)]$ | 0.3 |
| $\Delta v = 2.21\,\mathrm{km\,s^{-1}}$ (2.15–2.25) | 0.2 |
| $m_{p,\mathrm{ch}} = 261\,\mathrm{kg}$ (255–265) | 0.2 |
| Ratio $= 5.2$ | 0.1 |
:::

::: q D.2 0.5pt
Firing time.
:::

#### SOLUTION:

$$t = \frac{m_p}{\dot m} = \frac{50}{5.0\times10^{-6}} = 1.0\times10^7\,\mathrm{s} = 116\ \text{days}.$$

The thruster must run almost continuously for close to four months. This is the price of electric propulsion.

#### MARKING SCHEME:

::: marking
| $t = m_p/\dot m = 1.0\times10^7\,\mathrm{s}$ | 0.3 |
| $= 116$ days (114–118) | 0.2 |
:::

::: q D.3 0.5pt
Required solar array area.
:::

#### SOLUTION:

$$A = \frac{P}{0.30\,S_0} = \frac{1350}{0.30\times1361} = 3.31\,\mathrm{m^2}.$$

#### MARKING SCHEME:

::: marking
| $A = P/(0.30\,S_0)$ | 0.2 |
| $A = 3.31\,\mathrm{m^2}$ (3.2–3.4) | 0.3 |
:::

::: q D.4 0.5pt
Mass actually saved.
:::

#### SOLUTION:

$$m_\mathrm{array} = 3.31\times5.0 = 16.6\,\mathrm{kg}, \qquad m_\mathrm{PPU} = 1.35\times5.0 = 6.8\,\mathrm{kg},$$

$$m_\mathrm{power} = 23\,\mathrm{kg}.$$

The propellant saved relative to chemical propulsion is $261 - 50 = 211\,\mathrm{kg}$, so the net saving is

$$211 - 23 = 188\,\mathrm{kg}, \qquad \frac{188}{500} = 38\,\%.$$

Close to two fifths of the satellite mass is freed. It can go straight into extra communication transponders or a longer design life. For a wait of 116 days, that is a good bargain.

#### MARKING SCHEME:

::: marking
| $m_\mathrm{power} = 16.6 + 6.8 = 23\,\mathrm{kg}$ (21–25) | 0.3 |
| Net saving $188\,\mathrm{kg}$, $38\,\%$ of the initial mass (36–40) | 0.2 |
:::
