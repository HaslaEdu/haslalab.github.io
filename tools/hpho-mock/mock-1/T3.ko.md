2017년 10월, 하와이의 망원경 하나가 이상한 점을 하나 찾아냈다. 궤도를 맞춰 보니 타원이 아니라 쌍곡선이었다. 태양에 매인 적이 없는 천체, 다른 별에서 떠나와 우리 태양계를 스쳐 지나가는 중인 첫 번째 방문객이었다.

그런데 몇 달 뒤 더 이상한 일이 밝혀졌다. 이 천체가 중력만으로 계산한 궤도에서 조금씩 벗어나고 있었던 것이다. 어긋남은 아주 작았지만 관측 오차로 설명되지 않았다. 표면에서 무언가가 뿜어져 나오면서 아주 약한 로켓처럼 천체를 밀고 있다는 뜻이었다.

이 문제에서는 그런 방문객 하나를 처음부터 끝까지 따라간다. 어떤 궤도를 그리는지, 이런 천체가 얼마나 자주 오는지, 무엇이 궤도를 어긋나게 하는지, 그리고 이 가늘고 긴 천체가 왜 아직 부서지지 않았는지를 차례로 묻는다.

### 모형

- 천체는 태양의 중력만 받는 이체 문제로 다루며, 무한히 먼 곳에서의 속력은 $v_\infty$, 근일점 거리는 $q$이다. 행성의 섭동은 무시한다.
- 천체는 반장축 $a_1 = 300\,\mathrm{m}$, 반단축 $a_2 = a_3 = 50\,\mathrm{m}$인 균질한 회전타원체이고 밀도는 $\rho$이다. 자전축은 장축에 수직이며 자전 주기는 $T_\mathrm{rot}$이다.
- 표면이 받는 햇빛 가운데 반사되지 않은 몫은 모두 얼음의 승화에 쓰인다. 승화한 가스는 태양을 향한 방향으로 속력 $u$로 뿜어져 나간다. 태양 쪽 평균 투영 넓이는 $A_\odot$이다.
- 성간 천체는 태양 주위에 수밀도 $n$으로 고르게 분포하며, 모두 같은 $v_\infty$로 무작위 방향에서 들어온다고 본다.

## Part A - 쌍곡선 통과 (2.8점)

::: q A.1 0.5pt
에너지 보존과 각운동량 보존을 써서 근일점에서의 속력 $v_q$를 $v_\infty$, $GM_\odot$, $q$로 나타내고 값을 구하여라.
:::

::: q A.2 0.5pt
충격 매개변수 $b$(태양을 지나며 $\mathbf{v}_\infty$에 평행한 직선과 실제 점근선 사이의 거리)를 구하고 AU 단위로 값을 구하여라.
:::

::: q A.3 0.5pt
궤도의 이심률 $e$를 $q$, $v_\infty$, $GM_\odot$로 나타내고 값을 구하여라.
:::

::: q A.4 0.7pt
쌍곡선의 점근선 방향은 진근점이각 $\nu_\infty$가 $\cos\nu_\infty = -1/e$를 만족하는 방향이다. 들어올 때와 나갈 때의 속도 방향 사이의 각, 곧 편향각을 구하여라.
:::

::: q A.5 0.6pt
이 천체가 태양에서 $1\,\mathrm{AU}$ 안쪽에 머무는 시간을 어림하여라. 정확한 적분 대신 타당한 근사를 쓰되, 어떤 근사를 왜 썼는지 밝혀라.
:::

## Part B - 얼마나 자주 오는가 (1.7점)

::: q B.1 0.8pt
근일점이 $q_\mathrm{max}$보다 작아지려면 충격 매개변수가 얼마 이하여야 하는지 구하고, 이로부터 유효 충돌 단면적 $\sigma$를 $q_\mathrm{max}$, $GM_\odot$, $v_\infty$로 나타내어라. $q_\mathrm{max} = 1\,\mathrm{AU}$일 때 중력 집속 인자와 $\sigma$의 값을 구하여라.
:::

::: q B.2 0.6pt
수밀도 $n$으로부터 근일점이 $1\,\mathrm{AU}$ 안쪽인 성간 천체가 1년에 몇 개나 지나가는지 구하여라.
:::

::: q B.3 0.3pt
2017년부터 2025년까지 실제로 발견된 성간 천체는 3개이다. B.2의 결과와 견주어 무엇을 알 수 있는지 한 줄로 말하여라.
:::

## Part C - 궤도를 어긋나게 하는 힘 (3.5점)

::: q C.1 1.2pt
태양에서 거리 $r$일 때 흡수하는 복사 일률, 초당 승화하는 질량, 그리고 분출 반작용이 주는 비중력 가속도 $a_\mathrm{ng}$를 차례로 구하여라. 천체의 질량은 주어진 반축과 밀도로부터 직접 계산하여라. $r = q$에서의 $a_\mathrm{ng}$ 값을 구하여라.
:::

::: q C.2 0.5pt
$a_\mathrm{ng} = A_1/r^2$ 꼴로 쓸 때 $A_1$의 값을 구하고, $r = q$에서 태양 중력가속도와의 비를 구하여라.
:::

::: q C.3 0.6pt
근일점 부근에서 비중력 가속이 실질적으로 작용하는 시간을 $\tau \approx q/v_q$로 잡아, 그동안 쌓이는 속도 변화 $\Delta v$를 구하여라. 이것이 $v_\infty$에서 차지하는 비율은 얼마인가?
:::

::: q C.4 0.4pt
같은 시간 동안 잃는 질량이 전체 질량에서 차지하는 비율을 구하여라.
:::

::: q C.5 0.8pt
가스가 천체의 질량중심에서 벗어난 곳에서 뿜어 나오면 자전에 토크를 준다. 분출점이 질량중심에서 장축 방향으로 $0.01\,a_1$만큼 치우쳐 있다고 하자. 시간 $\tau$ 동안 받는 각운동량 변화를 현재 자전 각운동량과 견주어라. 균질한 회전타원체가 단축을 지나는 축에 대하여 갖는 관성 모멘트는 $I = \tfrac15 M(a_1^2 + a_2^2)$이다. 이 결과가 뜻하는 바를 말하여라.
:::

## Part D - 왜 아직 부서지지 않았는가 (2.0점)

::: q D.1 0.6pt
응집력이 전혀 없는 잔해 더미가 자체 중력만으로 버틸 수 있는 자전 주기의 하한 $T_\mathrm{min}$을 $G$와 $\rho$로 나타내고 값을 구하여라. 관측된 $T_\mathrm{rot}$과 견주어라.
:::

::: q D.2 0.8pt
천체를 길이 $2a_1$, 단면적이 일정한 균질한 막대로 보고, 자전 때문에 장축 한가운데에 걸리는 인장 응력을 구하여라. 자체 중력이 주는 압축 응력을 $\tfrac23\pi G\rho^2 R_\mathrm{eq}^2$($R_\mathrm{eq}$는 같은 부피를 갖는 구의 반지름)로 어림하여, 이 천체가 부서지지 않으려면 최소한 어느 정도의 응집력이 필요한지 구하여라.
:::

::: q D.3 0.6pt
응집력이 없는 천체가 태양의 조석력으로 부서지지 않으려면 근일점이 로슈 한계 $d = 2.44\,R_\odot(\rho_\odot/\rho)^{1/3}$ 밖에 있어야 한다. $d$를 AU 단위로 구하고 $q$와 견주어라.
:::
