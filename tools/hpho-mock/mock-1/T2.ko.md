정지궤도 통신위성을 $500\,\mathrm{kg}$으로 쏘아 올려 궤도를 $2.2\,\mathrm{km/s}$ 만큼 바꾸려 한다. 화학 로켓을 쓰면 추진제만 $261\,\mathrm{kg}$이 필요하다. 위성 무게의 절반이 연료인 셈이다.

같은 일을 전기추진으로 하면 추진제는 $50\,\mathrm{kg}$이면 된다. 대신 추력이 사과 한 개의 무게에도 못 미쳐서, 궤도를 다 바꾸는 데 넉 달이 걸린다. 무게를 살 것인가 시간을 살 것인가 — 1970년대부터 위성 설계자들이 붙들고 있는 물음이다.

이 맞바꿈을 가능하게 하는 장치가 홀 추력기다. 고리 모양의 방전실 안에서 전자는 자기장에 붙들려 방위 방향으로 뱅뱅 돌고, 그 전자 구름이 만드는 전기장이 무거운 제논 이온만 골라 축 방향으로 $21\,\mathrm{km/s}$까지 밀어낸다. 가벼운 것은 가두고 무거운 것은 내보내는, 질량 차이를 이용한 분리 장치인 셈이다.

### 모형

- 방전실은 평균 반지름 $R_c$, 폭 $w$ $(w \ll R_c)$인 고리 모양이고, 축 방향으로 길이 $L$인 구간에서 가속이 일어난다. 축 방향을 $+z$, 방위 방향을 $+\theta$, 반경 방향을 $+r$로 둔다.
- 자기장은 반경 방향으로 균일한 크기 $B$를 가진다. 전기장은 축 방향으로 균일하며 가속 구간 양 끝의 전위차는 $U_d$이다.
- 제논은 중성 원자로 들어와 방전실 안에서 한 번만 이온화되어 Xe$^+$가 된다. 이온은 정지 상태에서 출발하여 전위차 $U_d$ 전부를 받아 가속된다(C.3은 예외).
- 이온이 방전실을 지나는 동안 받는 자기력은 무시한다. 전자는 축 방향으로 거의 움직이지 못하고 방위 방향 드리프트만 한다고 본다.
- 방출된 이온 빔은 하류에서 중화기가 내보내는 전자와 만나 전기적으로 중성이 된다. 중화기가 쓰는 추진제와 전력은 무시한다.

## Part A - 이온을 얼마나 빠르게 내보내는가 (2.5점)

::: q A.1 0.5pt
정지 상태에서 출발한 Xe$^+$ 이온이 전위차 $U_d$ 전부를 받아 가속될 때의 출구 속력 $v_i$를 $e$, $U_d$, $m_i$로 나타내고 값을 구하여라.
:::

::: q A.2 0.7pt
이온 전류가 $I_i$일 때 단위 시간당 방출되는 이온의 질량과 추력 $F$를 $m_i$, $e$, $I_i$, $v_i$로 나타내어라. $F$의 값을 mN 단위로 구하여라.
:::

::: q A.3 0.3pt
비추력 $I_{sp} = v_i/g_0$의 값을 구하여라.
:::

::: q A.4 0.5pt
공급한 추진제 가운데 실제로 이온이 되어 가속된 몫을 추진제 이용률 $\eta_m$이라 한다. $\eta_m$을 $I_i$, $\dot m$, $m_i$, $e$로 나타내고 값을 구하여라.
:::

::: q A.5 0.5pt
가속 구간을 지나는 이온의 수밀도 $n_i$를 구하여라. 이 값을 표 1의 플라스마 밀도 $n_e$와 견주고, 두 값이 다른 까닭을 한 줄로 설명하여라.
:::

## Part B - 자기장이 하는 일 (3.2점)

자기장은 이온을 밀어내지 않는다. 자기장이 하는 일은 오직 하나, 전자가 양극으로 곧장 달려가지 못하게 막는 것이다. 전자가 갇히면 그 자리에 전위차가 유지되고, 그 전위차가 이온을 가속한다.

::: q B.1 0.8pt
전자의 열운동 속력을 $v_{te} = \sqrt{2eT_e/m_e}$로 잡을 때, 자기장 $B$ 속에서 전자가 그리는 원의 반지름 $r_{Le}$를 구하여라. 이 값을 채널 폭 $w$와 견주어라.
:::

::: q B.2 0.5pt
같은 자기장 속에서 속력 $v_i$로 움직이는 이온의 원 반지름 $r_{Li}$를 구하고, 가속 길이 $L$과 견주어라. 위 두 결과를 $r_{Le}$, $L$, $r_{Li}$ 사이의 부등식 하나로 정리하고, 그것이 이 장치의 작동 원리와 어떻게 이어지는지 말하여라.
:::

::: q B.3 0.6pt
서로 직교하는 균일한 $\mathbf{E}$와 $\mathbf{B}$ 속에서 알짜힘이 0이 되는 전자의 드리프트 속도를 구하고, 그 방향과 크기를 $E$, $B$로 나타내어라. 이 문제의 값으로 드리프트 속력 $v_d$를 구하여라.
:::

::: q B.4 1.3pt
방위 방향으로 흐르는 홀 전류 $I_H$(가속 구간 단면 $L\times w$를 지나는 전체 방위 전류)에 자기장이 주는 로런츠 힘의 축 방향 성분이 추력과 같음을 보여라. 이를 써서 $I_H$를 $F$, $B$, $R_c$로 나타내고 값을 구하여, 방전 전류 $I_d$의 몇 배인지 말하여라. 이어서 이 $I_H$로부터 가속 구간의 전자 수밀도를 되짚어 구하고, 표 1의 $n_e$와 견주어 모형의 자기 일관성을 논하여라.
:::

## Part C - 전리와 손실 (2.0점)

::: q C.1 0.7pt
중성 제논 원자가 방전실을 지나는 동안 전자와 부딪쳐 이온화될 때까지 움직이는 평균 거리는 $\lambda_\mathrm{ion} = v_n/(n_e\langle\sigma v\rangle)$이다. 이 값을 구하고 가속 길이 $L$과 견주어, A.4에서 얻은 $\eta_m$이 왜 1에 가까운지 설명하여라.
:::

::: q C.2 0.5pt
제논 원자 하나를 이온으로 만드는 데 드는 유효 에너지가 $\varepsilon$일 때, 전리에 쓰이는 전력이 전체 방전 전력 $P = U_d I_d$에서 차지하는 비율을 구하여라.
:::

::: q C.3 0.8pt
실제 추력기에서는 이온 빔이 반각 $\theta$로 퍼지므로 축 방향 운동량만 추력에 기여하고, 이온이 실제로 받는 전위차는 $U_\mathrm{eff} = 0.90\,U_d$에 지나지 않는다. 두 보정을 함께 넣은 추력과, 전체 추진제 유량으로 정의한 효율

$$\eta_a = \frac{F^2}{2\dot m P}$$

을 구하여라. 실제로 측정된 값은 $83\,\mathrm{mN}$, $\eta_a = 51\,\%$이다. 남은 차이를 만드는 원인을 하나 이상 들어라.
:::

:::

::: q D.2 0.5pt

:::

:::

::: q D.4 0.5pt
태양전지판과 전력처리장치의 질량을 표 1의 비질량으로 어림하고, 화학추진 대비 실제로 절약되는 질량을 구하여라. 그 값이 위성 초기 질량에서 차지하는 비율은 얼마인가?
