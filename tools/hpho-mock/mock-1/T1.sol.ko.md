## Part A - 물시계는 왜 느려지는가 (1.2점)

::: small
실라버스 유체역학(베르누이 정리)과 수학 부록(변수분리형 1계 미분방정식). 추가로 필요한 개념 없음.
:::

::: q A.1 0.5pt
물시계의 미분방정식과 총 배출 시간 $T_w$.
:::

#### SOLUTION:

구멍에서 나오는 부피 유량은 $a\sqrt{2gh}$이고, 이만큼 원통 안의 물이 줄어든다.

$$A\frac{dh}{dt} = -a\sqrt{2gh}.$$

변수를 분리하여 $h_0$에서 $0$까지 적분하면

$$T_w = \frac{A}{a}\int_0^{h_0}\frac{dh}{\sqrt{2gh}} = \frac{A}{a}\sqrt{\frac{2h_0}{g}}.$$

#### MARKING SCHEME:

::: marking
| $A\,dh/dt = -a\sqrt{2gh}$ | 0.3 |
| $T_w = (A/a)\sqrt{2h_0/g}$ | 0.2 |
:::

::: q A.2 0.3pt
$T_w$의 수치.
:::

#### SOLUTION:

$$\frac{a}{A} = \left(\frac{D}{2R}\right)^2 = \left(\frac{2.40}{24.0}\right)^2 = 1.00\times10^{-2},$$

$$T_w = \frac{1}{1.00\times10^{-2}}\sqrt{\frac{2\times0.126}{9.81}} = 16.0\,\mathrm{s}.$$

#### MARKING SCHEME:

::: marking
| $a/A = (D/2R)^2 = 1.00\times10^{-2}$ | 0.1 |
| $T_w = 16.0\,\mathrm{s}$ (15.8–16.2) | 0.2 |
:::

::: q A.3 0.4pt
앞뒤 절반의 배출 시간 비와 등시성 조건.
:::

#### SOLUTION:

높이 $h$에서 바닥까지 걸리는 시간은 $t(h) = (A/a)\sqrt{2h/g} \propto \sqrt{h}$이므로, 앞 절반에 걸리는 시간은 $t(h_0) - t(h_0/2) \propto \sqrt{h_0}\,(1 - 1/\sqrt2)$, 뒤 절반은 $\propto \sqrt{h_0}/\sqrt2$이다. 따라서

$$\frac{t_{\text{앞}}}{t_{\text{뒤}}} = \sqrt2 - 1 = 0.414,$$

곧 앞 절반이 전체의 $29.3\,\%$, 뒤 절반이 $70.7\,\%$를 차지한다. 물시계가 갈수록 느려지는 까닭은 유량이 남은 높이에 의존하기 때문이다. 시계가 등시성을 가지려면 **질량 유량이 남은 양과 무관하게 일정**해야 한다.

#### MARKING SCHEME:

::: marking
| $t(h)\propto\sqrt h$로부터 앞 절반 $\propto (1 - 1/\sqrt2)$ | 0.2 |
| 비 $= \sqrt2 - 1 = 0.414$ (앞 $29.3\,\%$ : 뒤 $70.7\,\%$) | 0.1 |
| 유량이 남은 양에 무관해야 등시성 | 0.1 |
:::

## Part B - 야센 응력 포화 (3.3점)

::: small
실라버스 정역학(마찰)과 수학 부록(상수계수 1계 선형 미분방정식). 야센 계수 $K$와 벽 마찰 관계는 실라버스 밖이므로 본문에서 식으로 주었다 [1]. Part B는 배출구를 막은 정지 상태를 다루므로 흐름과 무관하다.
:::

::: q B.1 1.1pt
얇은 층의 힘 평형에서 $\sigma_v(z)$를 얻기.
:::

#### SOLUTION:

깊이 $z$는 자유표면에서 아래로 잰다. 깊이 $z$와 $z+dz$ 사이 층에 작용하는 연직 방향 힘은 아래 면이 위로 미는 $\sigma_v(z+dz)\,\pi R^2$, 위 면이 아래로 미는 $\sigma_v(z)\,\pi R^2$, 자체 무게 $\rho_b g\,\pi R^2 dz$, 그리고 옆면 둘레 $2\pi R$에 걸리는 벽 마찰 $\tau_w\,2\pi R\,dz = \mu_w K\sigma_v\,2\pi R\,dz$이다. 평형에서

$$\pi R^2\,d\sigma_v = \rho_b g\,\pi R^2 dz - \mu_w K\sigma_v\,2\pi R\,dz$$

이므로

$$\frac{d\sigma_v}{dz} = \rho_b g - \frac{2\mu_w K}{R}\,\sigma_v.$$

이는 상수계수 1계 선형 방정식이고, $\sigma_v(0)=0$인 해는

$$\sigma_v(z) = \rho_b g\lambda\left(1 - e^{-z/\lambda}\right), \qquad \lambda = \frac{R}{2\mu_w K}.$$

깊이가 $\lambda$보다 훨씬 깊어지면 응력은 $\rho_b g\lambda$로 포화한다. 액체에서는 $K=0$이어서 $\lambda\to\infty$가 되고 정수압을 되찾는다.

#### MARKING SCHEME:

::: marking
| 층의 힘 평형에 벽 마찰 $\mu_w K\sigma_v\,2\pi R\,dz$ 포함 | 0.3 |
| $d\sigma_v/dz = \rho_b g - (2\mu_w K/R)\sigma_v$ | 0.3 |
| $\sigma_v(0)=0$ 적용, $\sigma_v = \rho_b g\lambda(1 - e^{-z/\lambda})$ | 0.3 |
| $\lambda = R/(2\mu_w K)$ | 0.2 |
:::

::: q B.2 0.4pt
$\lambda$와 $\sigma_v(h_0)$, 정수압과의 비교.
:::

#### SOLUTION:

$$\lambda = \frac{R}{2\mu_w K} = \frac{12.0\times10^{-3}}{2\times0.40\times0.50} = 3.00\times10^{-2}\,\mathrm{m} = 3.00\,\mathrm{cm},$$

$$\rho_b = \varphi\rho_p = 1.50\times10^{3}\,\mathrm{kg\,m^{-3}}, \qquad \rho_b g\lambda = 441\,\mathrm{Pa}.$$

$h_0/\lambda = 4.20$이므로

$$\sigma_v(h_0) = 441\times\left(1 - e^{-4.20}\right) = 435\,\mathrm{Pa}.$$

같은 깊이의 정수압은 $\rho_b g h_0 = 1854\,\mathrm{Pa}$이므로, 실제 바닥 응력은 그 $1/4.26$에 지나지 않는다.

#### MARKING SCHEME:

::: marking
| $\lambda = 3.00\,\mathrm{cm}$ | 0.2 |
| $\sigma_v(h_0) = 435\,\mathrm{Pa}$ (430–440) | 0.1 |
| 정수압 $1854\,\mathrm{Pa}$의 $1/4.3$ | 0.1 |
:::

::: q B.3 0.5pt
바닥이 받는 힘과 전체 무게의 비.
:::

#### SOLUTION:

$$F = \sigma_v(h_0)\,\pi R^2 = 435\times4.524\times10^{-4} = 0.197\,\mathrm{N},$$

$$M = \rho_b\,\pi R^2 h_0 = 85.5\,\mathrm{g}, \qquad Mg = 0.839\,\mathrm{N}.$$

$$\frac{F}{Mg} = 23.5\,\%.$$

나머지 $76.5\,\%$는 벽 마찰이 떠받친다. 알갱이 기둥의 바닥이 알갱이 무게보다 훨씬 작은 힘만 받는 이 현상이 야센 효과이다.

#### MARKING SCHEME:

::: marking
| $F = \sigma_v(h_0)\pi R^2 = 0.197\,\mathrm{N}$ (0.19–0.20) | 0.2 |
| $M = 85.5\,\mathrm{g}$, $Mg = 0.839\,\mathrm{N}$ | 0.1 |
| $23.5\,\%$ (22–25), 나머지는 벽 마찰 | 0.2 |
:::

::: q B.4 0.6pt
포화 조건이 깨지는 시간 비율과 야센 설명의 한계.
:::

#### SOLUTION:

$1 - e^{-h/\lambda} \geq 0.95$에서 $h \geq \lambda\ln 20 = 3.00\lambda = 9.0\,\mathrm{cm}$이다. 질량 유량이 일정하므로 남은 높이는 시간에 대하여 선형으로 줄고, $h < 9.0\,\mathrm{cm}$인 구간이 전체 배출 시간에서 차지하는 비율은

$$\frac{9.0}{12.6} = 71\,\%.$$

곧 모래시계가 작동하는 시간의 대부분에서 바닥 응력은 포화값에서 $5\,\%$ 넘게 벗어나며, 마지막에는 $0$까지 떨어진다. **야센 포화만으로는 등시성을 설명할 수 없다.** 등시성의 원인은 압력이 아니라 배출구 위의 아치에서 찾아야 한다.

#### MARKING SCHEME:

::: marking
| $1 - e^{-h/\lambda} \geq 0.95 \Rightarrow h \geq 3\lambda = 9.0\,\mathrm{cm}$ | 0.3 |
| 시간 비율 $= 9.0/12.6 = 71\,\%$ | 0.2 |
| 야센 포화만으로 등시성 설명 불가 | 0.1 |
:::

::: q B.5 0.7pt
저울 위의 겉보기 질량.
:::

#### SOLUTION:

저울이 받는 힘은 바닥이 떠받치는 힘이므로 B.1의 해를 그대로 쓰면

$$M_{\mathrm{app}}(h) = \frac{\sigma_v(h)\,\pi R^2}{g} = \rho_b\pi R^2\lambda\left(1 - e^{-h/\lambda}\right).$$

$h$를 늘려도 괄호 안이 1을 넘지 못하므로 겉보기 질량은

$$M_{\mathrm{app}}^{\infty} = \rho_b\pi R^2\lambda = 1.50\times10^{3}\times4.524\times10^{-4}\times3.00\times10^{-2} = 2.04\times10^{-2}\,\mathrm{kg} = 20.4\,\mathrm{g}$$

으로 포화한다. $h_0 = 12.6\,\mathrm{cm}$에서는 $20.4\times0.985 = 20.1\,\mathrm{g}$이고, 이는 B.3의 $F = 0.197\,\mathrm{N}$을 $g$로 나눈 $20.1\,\mathrm{g}$과 같다.

곧 이 원통에 알갱이를 $1\,\mathrm{m}$ 높이로 채워도 저울은 여전히 $20.4\,\mathrm{g}$을 가리킨다. 실제 질량은 $679\,\mathrm{g}$인데도 그렇다. 넘치는 무게는 전부 벽 마찰이 떠받쳐 스탠드로 빠져나가기 때문이다. 야센이 1895년에 곡물 창고에서 실제로 확인한 것이 바로 이 현상이며, 사일로 벽을 바닥보다 훨씬 튼튼하게 설계하는 이유이기도 하다.

#### MARKING SCHEME:

::: marking
| $M_{\mathrm{app}} = \rho_b\pi R^2\lambda(1 - e^{-h/\lambda})$ | 0.3 |
| 포화값 $M_{\mathrm{app}}^{\infty} = \rho_b\pi R^2\lambda = 20.4\,\mathrm{g}$ (19–22) | 0.2 |
| $h_0$에서 $20.1\,\mathrm{g}$, B.3과 일치 | 0.1 |
| 남는 무게는 벽 마찰이 떠받침 | 0.1 |
:::

## Part C - 자유낙하 아치와 Beverloo 법칙 (3.8점)

::: small
실라버스 역학(자유낙하)과 차원해석. 자유낙하 아치 모형과 Beverloo 상수는 실라버스 밖이므로 본문에서 주었다 [2, 3]. 막힘 조건도 마찬가지이다 [4].
:::

::: q C.1 1.0pt
아치 모형과 $Q_m \propto \rho_b\sqrt g D^{5/2}$의 유도.
:::

#### SOLUTION:

아치 아래에는 응력이 걸리지 않으므로 알갱이는 정지 상태에서 출발하여 자유낙하한다. 아치의 높이를 $H_{\mathrm{arch}} = k_1 D$ (본문 가정, $k_1$은 무차원 상수)라 하면 배출구를 지날 때의 속도는

$$v = \sqrt{2gH_{\mathrm{arch}}} = \sqrt{2k_1}\,\sqrt{gD} \;\propto\; \sqrt{gD}.$$

배출구 넓이가 $\frac{\pi}{4}D^2$이므로 질량 유량은

$$Q_m = \rho_b\cdot\frac{\pi}{4}D^2\cdot v \;\propto\; \rho_b\sqrt g\,D^{5/2}.$$

같은 결과를 차원해석으로도 얻는다. $Q_m$이 $\rho_b, g, D$만의 함수라면 $Q_m = \mathrm{const}\times\rho_b^{\alpha}g^{\beta}D^{\gamma}$에서 $\alpha = 1$, $\beta = \tfrac12$, $\gamma = \tfrac52$가 유일한 해이다. 핵심은 $h$가 어디에도 들어오지 않는다는 점이다.

#### MARKING SCHEME:

::: marking
| 아치 아래는 응력 $0$, 정지에서 자유낙하 | 0.3 |
| 아치 높이 $\propto D \Rightarrow v \propto \sqrt{gD}$ | 0.3 |
| $Q_m = \rho_b(\pi/4)D^2 v \propto \rho_b\sqrt g D^{5/2}$ | 0.4 |
:::

::: q C.2 0.6pt
빈 고리 보정과 등시성.
:::

#### SOLUTION:

알갱이의 중심은 배출구 가장자리에서 최소한 $d/2$만큼 안쪽에 있어야 통과할 수 있다. 따라서 실제로 흐름이 지나는 유효 지름은 $D$가 아니라 $D - kd$이고($k$는 $1$ 부근의 무차원 상수),

$$Q_m = C\rho_b\sqrt g\,(D - kd)^{5/2}.$$

양쪽에서 폭 $d/2$씩 빼면 $k = 1$이지만, 이 논증은 $k$의 자릿수만 정해 준다. 표 1의 $k = 1.4$는 실측값이다 [2].

이 식의 오른쪽에는 남은 높이 $h$도, 바닥 응력도 들어 있지 않다. 즉 배출 속도는 배출구의 기하만으로 정해지며 위에 얼마나 쌓여 있는지와 무관하다. 그러므로 $dM/dt = -Q_m$은 상수이고, 모래시계는 등시성을 갖는다.

#### MARKING SCHEME:

::: marking
| 가장자리 폭 $\sim d/2$의 빈 고리 $\Rightarrow$ 유효 지름 $D - kd$ | 0.3 |
| $Q_m = C\rho_b\sqrt g(D - kd)^{5/2}$ | 0.2 |
| $h$가 들어 있지 않으므로 유량이 일정 $\Rightarrow$ 등시성 | 0.1 |
:::

::: q C.3 0.6pt
$Q_m$, $M$, $T$의 수치.
:::

#### SOLUTION:

$$D - kd = 2.40 - 1.4\times0.30 = 1.98\,\mathrm{mm},$$

$$Q_m = 0.58\times1.50\times10^{3}\times\sqrt{9.81}\times(1.98\times10^{-3})^{5/2} = 4.75\times10^{-4}\,\mathrm{kg\,s^{-1}},$$

$$M = \rho_b\,\pi R^2 h_0 = 1.50\times10^{3}\times4.524\times10^{-4}\times0.126 = 8.55\times10^{-2}\,\mathrm{kg},$$

$$T = \frac{M}{Q_m} = \frac{8.55\times10^{-2}}{4.75\times10^{-4}} = 180\,\mathrm{s}.$$

정확히 3분이다. 같은 원통, 같은 구멍에 물을 담았을 때의 $16.0\,\mathrm{s}$와 견주면 모래는 11배 느리게 빠지며, 게다가 그 속도가 끝까지 변하지 않는다.

#### MARKING SCHEME:

::: marking
| $D - kd = 1.98\,\mathrm{mm}$ | 0.1 |
| $Q_m = 4.75\times10^{-4}\,\mathrm{kg\,s^{-1}}$ (4.6–4.9) | 0.2 |
| $M = 85.5\,\mathrm{g}$ | 0.1 |
| $T = 180\,\mathrm{s}$ (175–185) | 0.2 |
:::

::: q C.4 0.4pt
배출 속도와 아치 높이의 자기 일관성.
:::

#### SOLUTION:

$$v = \frac{Q_m}{\rho_b\,\frac{\pi}{4}(D - kd)^2} = \frac{4.75\times10^{-4}}{1.50\times10^{3}\times3.079\times10^{-6}} = 0.103\,\mathrm{m\,s^{-1}},$$

$$H_{\mathrm{arch}} = \frac{v^2}{2g} = \frac{(0.103)^2}{2\times9.81} = 5.4\times10^{-4}\,\mathrm{m} = 0.54\,\mathrm{mm} \approx \frac{D}{4}.$$

아치 높이가 배출구 지름과 같은 자릿수이므로 「아치 높이 $\propto D$」라는 가정과 무모순이다.

#### MARKING SCHEME:

::: marking
| $v = Q_m/[\rho_b\pi(D - kd)^2/4] = 0.103\,\mathrm{m\,s^{-1}}$ | 0.2 |
| $H = v^2/2g = 0.54\,\mathrm{mm} \approx D/4$, 모형과 무모순 | 0.2 |
:::

::: q C.5 0.5pt
막힘 한계와 설계 여유.
:::

#### SOLUTION:

실험으로 얻은 막힘 조건 $D/d \gtrsim 6$ [4]에서

$$D_{\mathrm{min}} \approx 6d = 6\times0.30 = 1.8\,\mathrm{mm}.$$

표 1의 값은 $D/d = 2.40/0.30 = 8.0$이므로 한계보다

$$\frac{8.0 - 6}{6} = 33\,\%$$

의 여유밖에 없다. 알갱이가 조금만 커지거나 구멍이 조금만 작아지면 아치가 무너지지 않고 그대로 멈춘다. 모래시계의 알갱이 크기를 엄격히 고르는 이유이다.

#### MARKING SCHEME:

::: marking
| $D_{\mathrm{min}} \approx 6d = 1.8\,\mathrm{mm}$ | 0.2 |
| $D/d = 8.0$ | 0.2 |
| 여유 $33\,\%$ | 0.1 |
:::

::: q C.6 0.7pt
알갱이 지름을 두 배로 하면.
:::

#### SOLUTION:

$$D - kd = 2.40 - 1.4\times0.60 = 1.56\,\mathrm{mm},$$

$$\frac{T'}{T} = \left(\frac{1.98}{1.56}\right)^{5/2} = 1.81 \;\Longrightarrow\; T' = 1.81\times180 = 327\,\mathrm{s}.$$

알갱이를 두 배로 키웠을 뿐인데 배출 시간이 1.8배로 늘어난다. 빈 고리의 폭이 알갱이 크기에 비례해서 커지므로 유효 배출 지름이 크게 줄기 때문이다.

그런데 막힘 조건을 다시 보면

$$\frac{D}{d} = \frac{2.40}{0.60} = 4.0 < 6$$

이므로 이 모래시계는 **아예 흐르지 않는다**. 아치가 한 번 걸리면 무너지지 않고 그대로 멈춘다. 위에서 구한 $327\,\mathrm{s}$는 계산상의 값일 뿐 실제로는 관측되지 않는다.

곧 알갱이 크기를 키우는 것은 두 방향에서 동시에 나쁘다. 유량이 급격히 줄고, 그와 동시에 막힘 한계에 가까워진다. 모래시계 제작자가 알갱이 크기를 좁은 범위로 체질하여 고르는 까닭이 여기에 있다.

#### MARKING SCHEME:

::: marking
| $D - kd = 1.56\,\mathrm{mm}$ | 0.2 |
| $T' = 327\,\mathrm{s}$ (300–350), 1.8배 | 0.3 |
| $D/d = 4.0 < 6$이므로 막혀서 흐르지 않음 | 0.2 |
:::

## Part D - 정밀도의 한계 (1.7점)

::: small
실라버스 수학 부록(오차 전파, 테일러 전개). 액체 다리 힘의 식은 실라버스 밖이므로 본문에서 주었다 [5].
:::

::: q D.1 0.4pt
$\Delta D$가 $T$에 주는 오차.
:::

#### SOLUTION:

$T = M/Q_m \propto (D - kd)^{-5/2}$이므로

$$\frac{\Delta T}{T} = \frac52\,\frac{\Delta D}{D - kd}.$$

$\Delta D = 0.05\,\mathrm{mm}$이면

$$\frac{\Delta T}{T} = \frac52\times\frac{0.05}{1.98} = 6.3\,\% \;\Longrightarrow\; \Delta T = \pm11\,\mathrm{s}.$$

#### MARKING SCHEME:

::: marking
| $\Delta T/T = (5/2)\Delta D/(D - kd)$ | 0.2 |
| $6.3\,\%$, $\Delta T = \pm11\,\mathrm{s}$ (10–12) | 0.2 |
:::

::: q D.2 0.4pt
3분 $\pm$ 1초에 필요한 가공 정밀도.
:::

#### SOLUTION:

$$\frac{\Delta T}{T} = \frac{1}{180} = 5.56\times10^{-3} \;\Longrightarrow\; \Delta D = \frac25\times5.56\times10^{-3}\times1.98\,\mathrm{mm} = 4.4\times10^{-3}\,\mathrm{mm} = 4.4\,\mu\mathrm{m}.$$

곧 정밀 모래시계를 만드는 일은 시계 기술의 문제가 아니라 구멍 가공의 문제이다. $5/2$라는 지수가 오차를 그대로 증폭하기 때문이다.

#### MARKING SCHEME:

::: marking
| $\Delta T/T = 1/180 = 5.56\times10^{-3}$ | 0.1 |
| $\Delta D = 4.4\,\mu\mathrm{m}$ (4.2–4.6) | 0.3 |
:::

::: q D.3 0.4pt
모형이 깨지는 마지막 구간의 비율.
:::

#### SOLUTION:

자유표면이 배출구에서 $2D$ 안쪽으로 들어오면 아치를 떠받칠 알갱이 층이 남아 있지 않다. 남은 높이가 $2D = 4.8\,\mathrm{mm}$일 때부터이므로, 유량이 일정함을 쓰면

$$\frac{2D}{h_0} = \frac{4.8}{126} = 3.8\,\%.$$

전체 시간의 $96\,\%$ 이상에서는 Beverloo 법칙이 잘 성립하고, 마지막 몇 초 동안만 유량이 흐트러진다. 실제 모래시계의 마지막 순간에 흐름이 눈에 띄게 불규칙해지는 것이 이 구간이다.

#### MARKING SCHEME:

::: marking
| $h \lesssim 2D$에서 아치 모형이 성립하지 않음 | 0.2 |
| $2D/h_0 = 3.8\,\%$ (3–5) | 0.2 |
:::

::: q D.4 0.5pt
액체 다리 힘과 밀봉의 필요성.
:::

#### SOLUTION:

알갱이 하나의 무게는 $W = \frac{\pi}{6}\rho_p g d^3$이므로

$$\frac{F_{\mathrm{cap}}}{W} = \frac{\pi\gamma d}{\frac{\pi}{6}\rho_p g d^3} = \frac{6\gamma}{\rho_p g d^2} = \frac{6\times0.072}{2.50\times10^{3}\times9.81\times(3.0\times10^{-4})^2} = 1.96\times10^{2}.$$

액체 다리 하나가 알갱이 무게의 $200$배에 가까운 힘으로 붙잡는다. 이 비가 $1$이 되는 임계 지름은 $d_c = \sqrt{6\gamma/\rho_p g} = 4.2\,\mathrm{mm}$이므로, 모래시계에 쓰는 크기의 알갱이는 습기만 있으면 예외 없이 서로 엉겨 붙는다. 그래서 모래시계는 반드시 **건조 상태로 밀봉**해야 하며, 이것이 유리를 완전히 봉하는 진짜 이유이다.

#### MARKING SCHEME:

::: marking
| $F_{\mathrm{cap}}/W = 6\gamma/(\rho_p g d^2)$ | 0.2 |
| $= 1.96\times10^{2}$ ($1.8$–$2.1\times10^{2}$) | 0.2 |
| 습기가 있으면 응집 $\Rightarrow$ 건조 밀봉 필요 | 0.1 |
:::
