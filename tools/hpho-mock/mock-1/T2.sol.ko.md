::: box 일반 규칙
- 이월 오차는 처음 한 번만 감점한다. 다만 차원이 맞지 않거나 크기·부호가 명백히 비물리적인 결과는 예외이다.
- 수치 값에 대한 점수(대개 0.1점)는 바탕이 되는 식이 옳을 때에만 준다.
- 유도 없이 최종 식만 적은 경우, 그 식을 기본 법칙에서 암산으로 얻을 수 있다고 판단되지 않으면 점수를 주지 않는다.
- 수치 답에는 단위를 적어야 점수를 준다. 괄호 안의 범위는 완전 점수를 주는 허용 구간이다.
- 서로 다른 접근법의 점수를 섞어 주지 않는다. 더 높은 쪽 하나만 인정한다.
:::

## Part A - 이온을 얼마나 빠르게 내보내는가 (2.5점)

::: intro
실라버스 역학(에너지 보존, 운동량)과 전자기학(전위차 속 하전입자). 추가로 필요한 개념 없음 [1].
:::

::: q A.1 0.5pt
이온의 출구 속력.
:::

#### SOLUTION:

전위차가 한 일이 모두 운동에너지가 되므로 $eU_d = \tfrac12 m_i v_i^2$,

$$v_i = \sqrt{\frac{2eU_d}{m_i}} = \sqrt{\frac{2\times1.602\times10^{-19}\times300}{2.180\times10^{-25}}} = 2.10\times10^4\,\mathrm{m\,s^{-1}} = 21.0\,\mathrm{km\,s^{-1}}.$$

#### MARKING SCHEME:

::: marking
| $eU_d = \tfrac12 m_i v_i^2$ | 0.2 |
| $v_i = 21.0\,\mathrm{km\,s^{-1}}$ (20.5–21.5) | 0.3 |
:::

::: q A.2 0.7pt
이온 질량 유량과 추력.
:::

#### SOLUTION:

초당 방출되는 이온의 개수는 $I_i/e$이므로 이온 질량 유량은

$$\dot m_i = \frac{m_i}{e} I_i = \frac{2.180\times10^{-25}}{1.602\times10^{-19}}\times3.50 = 4.76\times10^{-6}\,\mathrm{kg\,s^{-1}}.$$

추력은 단위 시간당 내보내는 운동량이므로

$$F = \dot m_i v_i = 4.76\times10^{-6}\times2.10\times10^4 = 0.100\,\mathrm{N} = 100\,\mathrm{mN}.$$

#### MARKING SCHEME:

::: marking
| $\dot m_i = (m_i/e) I_i = 4.76\times10^{-6}\,\mathrm{kg\,s^{-1}}$ | 0.3 |
| $F = \dot m_i v_i$ | 0.2 |
| $F = 100\,\mathrm{mN}$ (95–105) | 0.2 |
:::

::: q A.3 0.3pt
비추력.
:::

#### SOLUTION:

$$I_{sp} = \frac{v_i}{g_0} = \frac{2.10\times10^4}{9.81} = 2.14\times10^3\,\mathrm{s}.$$

화학추진의 비추력이 $300\,\mathrm{s}$ 안팎임을 생각하면 7배가량 크다.

#### MARKING SCHEME:

::: marking
| $I_{sp} = v_i/g_0 = 2.14\times10^3\,\mathrm{s}$ (2.1–2.2$\times10^3$) | 0.3 |
:::

::: q A.4 0.5pt
추진제 이용률.
:::

#### SOLUTION:

공급한 추진제가 모두 한 번씩 이온화된다면 얻을 수 있는 최대 이온 전류는

$$I_\mathrm{max} = \frac{e}{m_i}\dot m = \frac{1.602\times10^{-19}}{2.180\times10^{-25}}\times5.0\times10^{-6} = 3.67\,\mathrm{A}.$$

따라서

$$\eta_m = \frac{I_i}{I_\mathrm{max}} = \frac{3.50}{3.67} = 0.953 = 95.3\,\%.$$

#### MARKING SCHEME:

::: marking
| $I_\mathrm{max} = (e/m_i)\dot m = 3.67\,\mathrm{A}$ | 0.3 |
| $\eta_m = 95.3\,\%$ (93–97) | 0.2 |
:::

::: q A.5 0.5pt
가속 구간의 이온 수밀도.
:::

#### SOLUTION:

$w \ll R_c$이므로 고리의 단면적은

$$A_c = 2\pi R_c w = 2\pi\times0.0425\times0.0150 = 4.01\times10^{-3}\,\mathrm{m^2},$$

$$n_i = \frac{I_i}{eA_c v_i} = \frac{3.50}{1.602\times10^{-19}\times4.01\times10^{-3}\times2.10\times10^4} = 2.6\times10^{17}\,\mathrm{m^{-3}}.$$

표 1의 $n_e = 1.0\times10^{18}\,\mathrm{m^{-3}}$보다 약 4배 작다. 표 1의 값은 이온이 막 만들어지는 전리 영역의 밀도이고, 여기서 구한 값은 이온이 이미 가속된 뒤의 밀도이다. 정상 상태에서 입자 유량 $n_i v A_c$가 보존되어야 하므로 속력이 커지는 만큼 밀도가 작아진다.

#### MARKING SCHEME:

::: marking
| $A_c = 2\pi R_c w = 4.01\times10^{-3}\,\mathrm{m^2}$ | 0.2 |
| $n_i = I_i/(eA_c v_i) = 2.6\times10^{17}\,\mathrm{m^{-3}}$ (2.3–2.9) | 0.2 |
| 가속으로 속력이 커진 만큼 밀도가 작아짐 | 0.1 |
:::

## Part B - 자기장이 하는 일 (3.2점)

::: intro
실라버스 전자기학(로런츠 힘, 자기장 속 원운동)과 역학. $\mathbf{E}\times\mathbf{B}$ 드리프트는 힘의 평형에서 직접 얻으므로 별도의 개념을 주지 않았다 [1, 2].
:::

::: q B.1 0.8pt
전자의 라머 반지름.
:::

#### SOLUTION:

$$v_{te} = \sqrt{\frac{2eT_e}{m_e}} = \sqrt{\frac{2\times1.602\times10^{-19}\times20.0}{9.109\times10^{-31}}} = 2.65\times10^6\,\mathrm{m\,s^{-1}},$$

$$r_{Le} = \frac{m_e v_{te}}{eB} = \frac{9.109\times10^{-31}\times2.65\times10^6}{1.602\times10^{-19}\times1.50\times10^{-2}} = 1.0\times10^{-3}\,\mathrm{m} = 1.0\,\mathrm{mm}.$$

채널 폭과 견주면 $w/r_{Le} = 15.0/1.0 = 15$이므로, 전자는 벽에 닿기 전에 원을 여러 번 그린다. 곧 전자는 자기장에 확실히 붙들려 있다.

#### MARKING SCHEME:

::: marking
| $v_{te} = 2.65\times10^6\,\mathrm{m\,s^{-1}}$ | 0.3 |
| $r_{Le} = m_e v_{te}/(eB) = 1.0\,\mathrm{mm}$ (0.95–1.1) | 0.3 |
| $w/r_{Le} \approx 15$, 전자는 자화되어 있음 | 0.2 |
:::

::: q B.2 0.5pt
이온의 라머 반지름과 위계.
:::

#### SOLUTION:

$$r_{Li} = \frac{m_i v_i}{eB} = \frac{2.180\times10^{-25}\times2.10\times10^4}{1.602\times10^{-19}\times1.50\times10^{-2}} = 1.9\,\mathrm{m}, \qquad \frac{r_{Li}}{L} = 76.$$

따라서

$$r_{Le}\,(1\,\mathrm{mm}) \ll L\,(25\,\mathrm{mm}) \ll r_{Li}\,(1.9\,\mathrm{m}).$$

같은 자기장이 전자는 완전히 가두고 이온은 전혀 건드리지 못한다. 질량이 $2.4\times10^5$배 차이 나기 때문이다. 이 비대칭 덕분에 전자만 갇혀 전위차를 떠받치고, 이온은 그 전위차를 그대로 받아 직진 가속된다. 홀 추력기의 작동 원리 전체가 이 부등식 하나에 들어 있다.

#### MARKING SCHEME:

::: marking
| $r_{Li} = m_i v_i/(eB) = 1.9\,\mathrm{m}$ (1.8–2.0) | 0.2 |
| $r_{Li}/L = 76$ | 0.1 |
| $r_{Le} \ll L \ll r_{Li}$, 전자만 가두고 이온은 통과 | 0.2 |
:::

::: q B.3 0.6pt
$\mathbf{E}\times\mathbf{B}$ 드리프트.
:::

#### SOLUTION:

전자에 작용하는 알짜힘이 0이 되는 속도 $\mathbf{v}_d$는

$$-e(\mathbf{E} + \mathbf{v}_d\times\mathbf{B}) = 0 \;\Longrightarrow\; \mathbf{v}_d = \frac{\mathbf{E}\times\mathbf{B}}{B^2}, \qquad v_d = \frac{E}{B}.$$

방향은 $\mathbf{E}$와 $\mathbf{B}$ 둘 다에 수직, 곧 방위 방향이며 전하의 부호와 무관하다. $E = U_d/L = 300/0.0250 = 1.20\times10^4\,\mathrm{V\,m^{-1}}$이므로

$$v_d = \frac{1.20\times10^4}{1.50\times10^{-2}} = 8.0\times10^5\,\mathrm{m\,s^{-1}}.$$

#### MARKING SCHEME:

::: marking
| $-e(\mathbf{E} + \mathbf{v}_d\times\mathbf{B}) = 0$ | 0.3 |
| $\mathbf{v}_d = (\mathbf{E}\times\mathbf{B})/B^2$, 방위 방향 | 0.2 |
| $v_d = E/B = 8.0\times10^5\,\mathrm{m\,s^{-1}}$ | 0.1 |
:::

::: q B.4 1.3pt
홀 전류와 추력의 관계, 그리고 모형의 자기 일관성.
:::

#### SOLUTION:

방위 방향 전류밀도 $j_\theta$가 반경 방향 자기장 $B_r$ 속에 있으면 단위 부피당 $\mathbf{j}\times\mathbf{B}$의 힘을 받고, 그 방향은 축 방향이다. 가속 구간 전체에 대하여 적분하면

$$F = \int j_\theta B\,dV = B\int j_\theta\,dV = B\,(2\pi R_c)\int j_\theta\,dA = I_H B\,(2\pi R_c),$$

여기서 $I_H = \int j_\theta\,dA$는 단면 $L\times w$를 지나는 전체 방위 전류이다. 이 힘은 플라스마가 자기장(곧 자기회로와 추력기 본체)에 주는 힘과 크기가 같고 방향이 반대이므로, 뉴턴의 제3법칙에 따라 추력기가 받는 추력과 같다. **추력은 이온이 벽을 밀어서가 아니라 홀 전류가 자석을 밀어서 전달된다.**

따라서

$$I_H = \frac{F}{B\,(2\pi R_c)} = \frac{0.100}{1.50\times10^{-2}\times0.267} = 25.0\,\mathrm{A}, \qquad \frac{I_H}{I_d} = \frac{25.0}{4.50} = 5.5.$$

홀 전류는 방전 전류의 5.5배나 된다. 겉으로 흐르는 전류보다 안에서 도는 전류가 훨씬 큰 것이다.

되짚어 보면 $I_H = n_e e v_d\,(Lw)$이므로

$$n_e = \frac{I_H}{e v_d L w} = \frac{25.0}{1.602\times10^{-19}\times8.0\times10^5\times2.50\times10^{-2}\times1.50\times10^{-2}} = 5.2\times10^{17}\,\mathrm{m^{-3}}.$$

표 1의 $1.0\times10^{18}\,\mathrm{m^{-3}}$의 절반으로, 같은 자릿수이다. 가속 구간의 밀도가 전리 영역보다 낮다는 A.5의 결론과도 방향이 맞으므로 모형은 자기 일관적이다.

#### MARKING SCHEME:

::: marking
| $F = \int j_\theta B\,dV = I_H B(2\pi R_c)$ | 0.5 |
| 뉴턴 제3법칙으로 이 힘이 추력과 같음 | 0.2 |
| $I_H = F/[B(2\pi R_c)] = 25.0\,\mathrm{A}$ (24–26) | 0.3 |
| $I_H/I_d = 5.5$ | 0.1 |
| $n_e = I_H/(e v_d L w) = 5.2\times10^{17}\,\mathrm{m^{-3}}$, 같은 자릿수 | 0.2 |
:::

## Part C - 전리와 손실 (2.0점)

::: intro
실라버스 기체분자운동론(평균자유행로)과 에너지 수지. 전리 반응계수와 유효 전리 비용은 실라버스 밖이므로 본문에서 주었다 [1, 4].
:::

::: q C.1 0.7pt
전리 평균자유행로.
:::

#### SOLUTION:

$$\lambda_\mathrm{ion} = \frac{v_n}{n_e\langle\sigma v\rangle} = \frac{300}{1.0\times10^{18}\times2.0\times10^{-13}} = 1.5\times10^{-3}\,\mathrm{m} = 1.5\,\mathrm{mm}.$$

가속 길이와 견주면 $L/\lambda_\mathrm{ion} = 25.0/1.5 = 17$이다. 중성 원자는 방전실을 빠져나가기 전에 평균 17번 이온화될 기회를 만나므로, 살아서 그냥 통과할 확률은 $e^{-17} \sim 10^{-8}$에 지나지 않는다. A.4에서 $\eta_m$이 1에 가까웠던 까닭이 이것이다.

#### MARKING SCHEME:

::: marking
| $\lambda_\mathrm{ion} = v_n/(n_e\langle\sigma v\rangle) = 1.5\,\mathrm{mm}$ | 0.3 |
| $L/\lambda_\mathrm{ion} = 17$ | 0.2 |
| 통과 확률이 매우 작아 $\eta_m \approx 1$ | 0.2 |
:::

::: q C.2 0.5pt
전리에 쓰이는 전력의 비율.
:::

#### SOLUTION:

초당 만들어지는 이온이 $I_i/e$개이고 하나당 $\varepsilon$의 에너지가 들므로

$$P_\mathrm{ion} = \frac{I_i}{e}\varepsilon = I_i\times25\,\mathrm{V} = 3.50\times25 = 87.5\,\mathrm{W}.$$

전체 방전 전력은 $P = U_d I_d = 300\times4.50 = 1350\,\mathrm{W}$이므로

$$\frac{P_\mathrm{ion}}{P} = \frac{87.5}{1350} = 6.5\,\%.$$

전리는 생각보다 싸다. $300\,\mathrm{V}$를 가속에 쓰는데 이온 하나를 만드는 데는 $25\,\mathrm{V}$어치면 되기 때문이다. 방전 전압을 높일수록 이 비율은 더 떨어진다.

#### MARKING SCHEME:

::: marking
| $P_\mathrm{ion} = (I_i/e)\varepsilon = 87.5\,\mathrm{W}$ | 0.3 |
| $P_\mathrm{ion}/P = 6.5\,\%$ (6–7) | 0.2 |
:::

::: q C.3 0.8pt
빔 발산과 전압 이용률을 넣은 실제 성능.
:::

#### SOLUTION:

전위차가 $U_\mathrm{eff} = 0.90\,U_d$이면 속력은 $\sqrt{0.90}$배가 되고, 축 방향 성분만 추력에 기여하므로 $\cos\theta$가 곱해진다.

$$F = \dot m_i v_i\sqrt{0.90}\,\cos 15^\circ = 0.100\times0.9487\times0.9659 = 9.16\times10^{-2}\,\mathrm{N} = 91.6\,\mathrm{mN},$$

$$\eta_a = \frac{F^2}{2\dot m P} = \frac{(9.16\times10^{-2})^2}{2\times5.0\times10^{-6}\times1350} = \frac{8.40\times10^{-3}}{1.35\times10^{-2}} = 0.622 = 62.2\,\%.$$

측정값 $83\,\mathrm{mN}$, $51\,\%$와는 아직 차이가 있다. 남은 원인으로는 Xe$^{2+}$ 같은 다가 이온의 생성(같은 전류에 더 적은 질량을 실어 나른다), 채널 벽과의 충돌에서 잃는 이온과 에너지, 그리고 자기회로와 중화기가 쓰는 전력 등이 있다.

#### MARKING SCHEME:

::: marking
| $F = \dot m_i v_i\sqrt{0.90}\cos\theta$ | 0.3 |
| $F = 91.6\,\mathrm{mN}$ (89–94) | 0.2 |
| $\eta_a = 62.2\,\%$ (60–65) | 0.2 |
| 다가 이온 / 벽 손실 / 부대 전력 중 하나 이상 | 0.1 |
:::

## Part D - 무게를 살 것인가 시간을 살 것인가 (2.3점)

::: intro
실라버스 역학(변질량계, 로켓 방정식)과 열복사·에너지 수지. 추가로 필요한 개념 없음 [1].
:::

::: q D.1 0.8pt
$\Delta v$와 화학추진과의 추진제 비교.
:::

#### SOLUTION:

$$\Delta v = v_i\ln\frac{m_0}{m_0 - m_p} = 2.10\times10^4\times\ln\frac{500}{450} = 2.21\times10^3\,\mathrm{m\,s^{-1}}.$$

같은 $\Delta v$를 배기속도 $v_\mathrm{ch}$로 얻으려면

$$m_f = m_0 e^{-\Delta v/v_\mathrm{ch}} = 500\,e^{-0.737} = 239\,\mathrm{kg} \;\Longrightarrow\; m_{p,\mathrm{ch}} = 500 - 239 = 261\,\mathrm{kg},$$

$$\frac{m_{p,\mathrm{ch}}}{m_p} = \frac{261}{50} = 5.2.$$

배기속도가 7배 크므로 지수 안의 값이 7분의 1이 되고, 그 결과 추진제는 5배 넘게 줄어든다.

#### MARKING SCHEME:

::: marking
| $\Delta v = v_i\ln[m_0/(m_0 - m_p)]$ | 0.3 |
| $\Delta v = 2.21\,\mathrm{km\,s^{-1}}$ (2.15–2.25) | 0.2 |
| $m_{p,\mathrm{ch}} = 261\,\mathrm{kg}$ (255–265) | 0.2 |
| 비 $= 5.2$ | 0.1 |
:::

::: q D.2 0.5pt
연소 시간.
:::

#### SOLUTION:

$$t = \frac{m_p}{\dot m} = \frac{50}{5.0\times10^{-6}} = 1.0\times10^7\,\mathrm{s} = 116\,\text{일}.$$

넉 달 가까이 추력기를 계속 켜 두어야 한다. 이것이 전기추진이 치르는 대가다.

#### MARKING SCHEME:

::: marking
| $t = m_p/\dot m = 1.0\times10^7\,\mathrm{s}$ | 0.3 |
| $= 116$ 일 (114–118) | 0.2 |
:::

::: q D.3 0.5pt
필요한 태양전지판 넓이.
:::

#### SOLUTION:

$$A = \frac{P}{0.30\,S_0} = \frac{1350}{0.30\times1361} = 3.31\,\mathrm{m^2}.$$

#### MARKING SCHEME:

::: marking
| $A = P/(0.30\,S_0)$ | 0.2 |
| $A = 3.31\,\mathrm{m^2}$ (3.2–3.4) | 0.3 |
:::

::: q D.4 0.5pt
실제로 절약되는 질량.
:::

#### SOLUTION:

$$m_\mathrm{array} = 3.31\times5.0 = 16.6\,\mathrm{kg}, \qquad m_\mathrm{PPU} = 1.35\times5.0 = 6.8\,\mathrm{kg},$$

$$m_\text{전력계} = 23\,\mathrm{kg}.$$

화학추진 대비 추진제 절감은 $261 - 50 = 211\,\mathrm{kg}$이므로 순 절감은

$$211 - 23 = 188\,\mathrm{kg}, \qquad \frac{188}{500} = 38\,\%.$$

위성 질량의 5분의 2에 가까운 여유가 생긴다. 이 여유는 곧바로 통신 중계기를 더 싣거나 설계 수명을 늘리는 데 쓰인다. 116일을 기다리는 값으로는 충분히 남는 거래다.

#### MARKING SCHEME:

::: marking
| $m_\text{전력계} = 16.6 + 6.8 = 23\,\mathrm{kg}$ (21–25) | 0.3 |
| 순 절감 $188\,\mathrm{kg}$, 초기 질량의 $38\,\%$ (36–40) | 0.2 |
:::
