::: box 일반 규칙
- 실험 문제이므로 참값 대신 허용 구간으로 채점한다. 괄호 안의 넓은 구간은 부분 점수, 좁은 구간은 완전 점수를 준다.
- 불확도를 요구한 항목에서 불확도가 빠지면 해당 배점의 절반만 준다. 불확도의 크기가 참값의 $1/3$–$3$배 안에 들면 인정한다.
- 그래프에는 축 이름과 단위가 있어야 하고, 자료점이 그래프 넓이의 절반 이상에 퍼져 있어야 완전 점수를 준다.
- 이월 오차는 처음 한 번만 감점한다.
- Part D는 절차 서술이 없으면 수치에 점수를 주지 않는다.
:::

## Part A - 침투 법칙의 확인 (3.0점)

::: small
실라버스 유체역학(표면장력, 점성 흐름)과 수학 부록(로그 그래프, 최소제곱 직선, 오차 전파). Washburn 법칙은 실라버스 밖이므로 본문에서 주었다 [2].
:::

::: q A.1 0.8pt
$L(t_{\text{time}})$ 자료.
:::

#### SOLUTION:

전형적인 종이에서 $L = 10\,\mathrm{cm}$에 이르는 데 약 $500\,\mathrm{s}$가 걸린다. $L$의 불확도는 앞면이 번져 있으므로 눈금자의 최소 눈금보다 크게, $\pm1\,\mathrm{mm}$ 이상으로 잡는 것이 옳다. 자료점은 $t_{\text{time}}$이 아니라 $L$에 대하여 고르게 잡아야 로그 그래프에서 균형이 맞는다.

#### MARKING SCHEME:

::: marking
| 8점 이상, $L = 2$–$15\,\mathrm{cm}$에 고르게 분포 | 0.4 |
| $L$과 $t_{\text{time}}$의 불확도를 함께 적음 | 0.2 |
| $\delta L \geq 1\,\mathrm{mm}$ (앞면 번짐을 반영) | 0.2 |
:::

::: q A.2 0.9pt
로그-로그 기울기.
:::

#### SOLUTION:

$L = (K t_{\text{time}})^{1/2}$이므로 $\log L = \tfrac12\log t_{\text{time}} + \tfrac12\log K$이고 기울기는 $n = 0.500$이어야 한다. 실제 측정에서는

$$n = 0.50 \pm 0.03$$

정도가 나온다. $n$이 0.5보다 뚜렷하게 작다면 용기가 덜 닫혀 증발이 들어온 것이다(뚜껑 없이 재면 $n \approx 0.47$).

#### MARKING SCHEME:

::: marking
| 두 축 이름·단위, 자료점이 그래프의 절반 이상에 분포 | 0.3 |
| 기울기 $n = 0.50$ (0.44–0.56) | 0.3 |
| $\delta n$을 최소제곱 또는 최대·최소 기울기로 산출 | 0.2 |
| Washburn 예측 $1/2$과 일치함을 명시 | 0.1 |
:::

::: q A.3 0.8pt
$K$의 결정.
:::

#### SOLUTION:

$L^2$ 대 $t_{\text{time}}$ 그래프는 원점을 지나는 직선이고 기울기가 $K$이다.

$$K = 2.0\times10^{-5}\,\mathrm{m^2\,s^{-1}}.$$

절편이 뚜렷이 0이 아니면 담근 깊이나 시작 시각의 계통 오차가 있다는 뜻이다.

#### MARKING SCHEME:

::: marking
| $L^2$–$t_{\text{time}}$ 직선, 원점 통과 확인 | 0.3 |
| $K = 2.0\times10^{-5}\,\mathrm{m^2\,s^{-1}}$ (1.4–2.8) | 0.3 |
| $\delta K$ 산출 | 0.2 |
:::

::: q A.4 0.5pt
동적 유효 세공 반지름.
:::

#### SOLUTION:

$$r_d = \frac{2\mu_w K}{\gamma_w} = \frac{2\times1.00\times10^{-3}\times2.0\times10^{-5}}{0.0720} = 5.6\times10^{-7}\,\mathrm{m} = 0.56\,\mathrm{\mu m}.$$

#### MARKING SCHEME:

::: marking
| $r_d = 2\mu_w K/\gamma_w$ | 0.2 |
| $r_d = 0.56\,\mathrm{\mu m}$ (0.4–0.8) | 0.2 |
| $\delta r_d/r_d = \delta K/K$ | 0.1 |
:::

## Part B - 종이는 무엇으로 이루어져 있는가 (2.0점)

::: small
실라버스 측정 기법(질량·길이 측정, 겹쳐 재기)과 오차 전파.
:::

::: q B.1 0.7pt
두께와 흡수 질량.
:::

#### SOLUTION:

$n$장을 겹쳐 재면 두께의 불확도가 $1/n$로 줄어든다. 크로마토그래피 종이는 $t = 0.18\,\mathrm{mm}$ 안팎이다. $L = 12\,\mathrm{cm}$일 때 흡수 질량은

$$m = \varphi\rho_w b t L \approx 0.65\times1000\times0.015\times1.8\times10^{-4}\times0.12 = 0.21\,\mathrm{g}$$

정도이므로 $0.01\,\mathrm{g}$ 저울에서 20눈금 남짓이다. 꺼낸 뒤 지체하면 증발로 값이 줄어들므로 곧바로 재야 한다.

#### MARKING SCHEME:

::: marking
| 여러 장을 겹쳐 두께를 잼, $t = 0.18\,\mathrm{mm}$ (0.15–0.22) | 0.4 |
| $m = 0.21\,\mathrm{g}$ (0.12–0.30), 즉시 측정 | 0.3 |
:::

::: q B.2 0.8pt
공극률.
:::

#### SOLUTION:

$$\varphi = \frac{m}{\rho_w b t L} = 0.65.$$

불확도는 $t$가 지배한다. $\delta\varphi/\varphi = \sqrt{(\delta m/m)^2 + (\delta t/t)^2 + (\delta L/L)^2} \approx 10\,\%$ 안팎.

#### MARKING SCHEME:

::: marking
| $\varphi = m/(\rho_w b t L)$ | 0.3 |
| $\varphi = 0.65$ (0.45–0.80) | 0.3 |
| $\delta\varphi$ 산출, $t$가 지배함을 지적 | 0.2 |
:::

::: q B.3 0.5pt
$r_d$와 섬유 간격의 비교.
:::

#### SOLUTION:

셀룰로스 섬유의 지름은 $20\,\mathrm{\mu m}$ 안팎이고 공극률 0.65에서 빈틈의 크기도 같은 자릿수, 곧 $10\,\mathrm{\mu m}$ 정도이다. 이는 $r_d = 0.56\,\mathrm{\mu m}$보다 20배쯤 크다. 까닭으로는 (i) 실제 경로가 구불구불해서 겉보기 길이보다 훨씬 길다는 것(굴곡도), (ii) 세공 크기가 넓게 퍼져 있어 앞면의 진행을 가장 좁은 목이 지배한다는 것, (iii) 접촉각이 0이 아니어서 $\cos\theta < 1$이라는 것을 들 수 있다. 곧 $r_d$는 기하학적 구멍 크기가 아니라 흐름 저항을 대표하는 값이다.

#### MARKING SCHEME:

::: marking
| 빈틈 크기를 $\sim10\,\mathrm{\mu m}$로 어림, $r_d$의 10배 이상임을 지적 | 0.3 |
| 굴곡도 / 세공 분포 / $\cos\theta < 1$ 중 하나 이상 | 0.2 |
:::

## Part C - 표면장력을 바꾸면 (2.5점)

::: small
실라버스 유체역학(표면장력)과 오차 전파. 추가로 필요한 개념 없음 [3].
:::

::: q C.1 1.0pt
계면활성제 수용액의 $K_s$.
:::

#### SOLUTION:

같은 종이에서 표면장력이 낮아지면 침투가 느려진다.

$$K_s = 8.5\times10^{-6}\,\mathrm{m^2\,s^{-1}}$$

안팎이 나온다. 같은 스트립을 두 번 쓰면 안 되며, 접시를 바꿀 때 이전 액체가 남지 않도록 해야 한다.

#### MARKING SCHEME:

::: marking
| 6점 이상, $L^2$–$t_{\text{time}}$ 직선 | 0.4 |
| $K_s = 8.5\times10^{-6}\,\mathrm{m^2\,s^{-1}}$ (6–12) | 0.4 |
| $\delta K_s$ 산출 | 0.2 |
:::

::: q C.2 0.9pt
계면활성제 수용액의 표면장력.
:::

#### SOLUTION:

같은 종이이므로 $r_d\cos\theta$가 같다고 보면

$$\frac{K_s}{K_w} = \frac{\gamma_s/\mu_s}{\gamma_w/\mu_w} \;\Longrightarrow\; \gamma_s = \gamma_w\frac{\mu_s}{\mu_w}\frac{K_s}{K_w} = 72.0\times1.05\times\frac{8.5}{20} = 32\,\mathrm{mN\,m^{-1}}.$$

이는 대표적인 계면활성제 수용액의 임계 미셀 농도 위쪽 값과 잘 맞는다.

#### MARKING SCHEME:

::: marking
| $\gamma_s = \gamma_w(\mu_s/\mu_w)(K_s/K_w)$ | 0.4 |
| $\gamma_s = 32\,\mathrm{mN\,m^{-1}}$ (24–42) | 0.3 |
| $\delta\gamma_s$ 산출 | 0.2 |
:::

::: q C.3 0.6pt
접촉각 가정의 방향성.
:::

#### SOLUTION:

실제로 측정되는 것은 $\gamma\cos\theta$이다.

$$\gamma_s^{\text{측정}} = \gamma_s^{\text{참}}\,\frac{\cos\theta_s}{\cos\theta_w}.$$

계면활성제는 젖음을 돕기 때문에 $\theta_s < \theta_w$, 곧 $\cos\theta_s > \cos\theta_w$이다. 따라서 접촉각 차이를 무시하면 $\gamma_s$를 **참값보다 크게** 얻는다. 곧 위에서 얻은 $32\,\mathrm{mN\,m^{-1}}$은 상한이다.

#### MARKING SCHEME:

::: marking
| 측정량이 $\gamma\cos\theta$임을 지적 | 0.3 |
| $\cos\theta_s > \cos\theta_w$이므로 과대평가(상한) | 0.3 |
:::

## Part D - 증발 — 스스로 설계하기 (2.5점)

::: small
실라버스 열역학(증발)과 실험 설계·오차 예산. 포화 길이 식은 본문에서 주었다 [4].
:::

::: q D.1 1.0pt
포화 길이의 측정.
:::

#### SOLUTION:

증발이 있으면 $d(L^2)/dt_{\text{time}} = K\,(1 - (L/L_{\max})^2)$이므로 앞면은 멈추지 않고 $L_{\max}$에 점근적으로 다가가며, 시간 상수는 48분이다. 「10분에 $1\,\mathrm{mm}$ 미만」 같은 **변화율** 기준은 2.6시간 뒤 $L = 23.5\,\mathrm{cm}$에서야 충족된다. 대신 $L^2$에 대한 $\Delta(L^2)/\Delta t_{\text{time}}$ 그래프를 그리면 직선이 되고, 가로축 절편이 $L_{\max}$의 제곱이고 세로축 절편은 A.3의 $K$와 같아야 한다. 스트립을 시험 처음에 걸어 두고, $L$이 외삽한 $L_{\max}$의 90 %를 넘으면(약 80분, $L \approx 21.6\,\mathrm{cm}$) 측정을 끝낸다. 결과는 $L_{\max} = 24\,\mathrm{cm}$이다.

같은 스트립을 뚜껑 있는 용기 안에 넣어 되풀이하면 $L_{\max}$가 뚜렷이 커지는데, 이것이 증발이 원인임을 보이는 대조 실험이 된다.

#### MARKING SCHEME:

::: marking
| 종료 기준과 $L_{\max}$ 결정 방법을 정량 제시 | 0.4 |
| $L_{\max} = 24\,\mathrm{cm}$ (16–32) | 0.3 |
| $\delta L_{\max}$ 산출 | 0.1 |
| 밀폐 대조 실험으로 원인이 증발임을 확인 | 0.2 |
:::

::: q D.2 0.9pt
증발률.
:::

#### SOLUTION:

$$E = \frac{\varphi\rho_w t K}{4L_{\max}^2} = \frac{0.65\times1000\times1.8\times10^{-4}\times2.0\times10^{-5}}{4\times(0.24)^2} = 1.0\times10^{-5}\,\mathrm{kg\,m^{-2}\,s^{-1}}.$$

하루로 환산하면 $0.9\,\mathrm{kg\,m^{-2}}$, 곧 물 높이로 하루 $0.9\,\mathrm{mm}$로 실내 증발의 전형적인 값이다. 불확도는 $L_{\max}$가 제곱으로 들어가므로 그것이 지배한다.

#### MARKING SCHEME:

::: marking
| $E = \varphi\rho_w t K/(4L_{\max}^2)$ | 0.3 |
| $E = 1.0\times10^{-5}\,\mathrm{kg\,m^{-2}\,s^{-1}}$ (0.4–2.5) | 0.3 |
| $\delta E/E \approx 2\,\delta L_{\max}/L_{\max}$가 지배함을 지적 | 0.3 |
:::

::: q D.3 0.6pt
독립 측정과의 비교.
:::

#### SOLUTION:

가장 간단한 독립 측정은 접시에 담은 물의 질량 감소를 시간에 따라 재는 것이다. 넓이 $A$인 접시에서 $\Delta m$이 줄었다면 $E = \Delta m/(A\,\Delta t)$이다. 두 값이 다르다면 (i) 젖은 종이는 접시보다 표면적 대비 공기 흐름에 더 노출되어 증발이 빠르다는 점, (ii) 종이가 완전히 포화되지 않아 실효 두께가 $t$보다 작다는 점, (iii) 너무 이른 자료로 $L_{\max}$를 외삽했다는 점을 원인으로 들 수 있다. 두 값이 3배 안에 들어오면 잘 맞는 것으로 본다.

#### MARKING SCHEME:

::: marking
| 독립 방법(예: 접시의 질량 감소)을 실행하고 $E$를 산출 | 0.3 |
| 두 값을 정량 비교 | 0.1 |
| 차이의 원인을 하나 이상 지적 | 0.2 |
:::
