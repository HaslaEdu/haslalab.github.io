## Part A - 편광계 만들기 (1.5점)

::: small
실라버스 광학(편광, 말뤼스 법칙, 복굴절). 응력-광학 법칙은 실라버스 밖이므로 본문에서 주었다 [1].
:::

::: q A.1 0.6pt
교차 편광 상태의 확인.
:::

#### SOLUTION:

말뤼스 법칙 $I = I_0\cos^2\alpha$에 따라 두 투과축이 이루는 각이 $90^\circ$일 때 가장 어둡다. 소광 위치는 밝기 변화가 각도에 대해 가장 느린 곳이므로, 어두운 구간의 양 끝을 찾아 그 가운데를 취하면 정밀도가 높아진다.

#### MARKING SCHEME:

::: marking
| 소광 각 $= 90^\circ$ ($88$–$92^\circ$) | 0.4 |
| $I \propto \cos^2\alpha$를 근거로 제시 | 0.2 |
:::

::: q A.2 0.9pt
1/4 파장판의 구실.
:::

#### SOLUTION:

선편광계만 쓰면 하중을 건 시편을 돌릴 때 어두운 띠(등경선)가 함께 돌아간다. 이는 주응력 방향이 편광축과 나란해지는 자리에서 생기며 응력의 크기와는 무관하다. 1/4 파장판 두 장을 $45^\circ$로 넣어 원편광계를 만들면 입사 편광에 방향성이 없어지므로 등경선이 사라지고, 응력 차이만 나타내는 등색선만 남는다. 무늬 차수를 세려면 반드시 이 상태여야 한다.

하중을 걸지 않았는데도 무늬가 보인다면 성형 과정에서 굳은 잔류 응력이거나, 클램프가 시편을 물면서 준 응력이다. 이 초기 차수를 $N_0$로 기록해 두고 이후 값에서 빼야 한다.

#### MARKING SCHEME:

::: marking
| 선편광계에서 시편을 돌리면 어두운 띠가 함께 돌아감을 관찰 | 0.2 |
| 그것이 등경선이며 응력 크기와 무관함을 지적 | 0.2 |
| 원편광계에서 등경선이 사라지고 등색선만 남음 | 0.3 |
| 무하중 무늬 $=$ 잔류 응력 또는 클램프 응력, $N_0$로 보정 | 0.2 |
:::

## Part B - 응력 무늬값 재기 (2.6점)

::: small
실라버스 역학(응력)과 수학 부록(최소제곱 직선, 오차 전파).
:::

::: q B.1 1.0pt
$N$ 대 $F$ 자료.
:::

#### SOLUTION:

단순 인장에서 $\sigma_2 = 0$, $\sigma_1 = F/(b_1 t) = F/(1.20\times10^{-4}\,\mathrm{m^2})$이므로 무늬는 시편 전체에 고르게 나타나고, 하중을 올리면 무늬가 시편 가장자리에서 안쪽으로 밀려든다. 차수는 하중을 천천히 올리며 어느 지점을 지나가는 어두운 줄의 개수를 세어 정한다. 정수가 아닌 차수는 이웃한 두 어두운 줄 사이의 위치를 내삽하거나, 밝기가 최대인 곳을 반정수 차수로 잡아 읽는다.

$0.5$–$3.0\,\mathrm{kg}$에서 $N$은 대략 $1.2$부터 $7.4$까지 자란다.

#### MARKING SCHEME:

::: marking
| 6단계 이상, $N$이 1에서 7 부근까지 분포 | 0.4 |
| 비정수 차수를 읽는 방법을 구체적으로 서술 | 0.3 |
| $N$과 $F$의 불확도를 함께 적음 | 0.3 |
:::

::: q B.2 1.0pt
$f_\sigma$와 $C$.
:::

#### SOLUTION:

$$N = \frac{t}{f_\sigma}\,\frac{F}{b_1 t} = \frac{F}{b_1 f_\sigma} \quad\Longrightarrow\quad \text{기울기 } s = \frac{dN}{dF} = \frac{1}{b_1 f_\sigma}.$$

측정에서 $s = 0.25\,\mathrm{N^{-1}}$ 안팎이 나오므로

$$f_\sigma = \frac{1}{b_1 s} = \frac{1}{0.0200 \times 0.25} = 2.0\times10^{2}\,\mathrm{N\,m^{-1}},$$

$$C = \frac{\lambda}{f_\sigma} = \frac{546\times10^{-9}}{200} = 2.7\times10^{-9}\,\mathrm{Pa^{-1}} = 2.7\times10^{3}\ \text{Brewster}.$$

폴리우레탄이 폴리카보네이트보다 30배 넘게 민감하기 때문에 몇 kg의 하중만으로도 무늬를 셀 수 있다.

#### MARKING SCHEME:

::: marking
| $s = 1/(b_1 f_\sigma)$ 유도 | 0.3 |
| $f_\sigma = 2.0\times10^{2}\,\mathrm{N\,m^{-1}}$ ($1.5$–$2.6\times10^{2}$) | 0.3 |
| $C = 2.7\times10^{-9}\,\mathrm{Pa^{-1}}$ ($2.1$–$3.6$) | 0.2 |
| $\delta f_\sigma$ 산출 | 0.2 |
:::

::: q B.3 0.6pt
절편의 뜻과 오차 예산.
:::

#### SOLUTION:

0이 아닌 절편은 하중이 0일 때 이미 있던 차수, 곧 A.2에서 본 잔류 응력과 클램프 응력을 뜻한다. 추걸이 무게를 빼먹으면 절편은 양이 되고, 음의 절편은 하중과 반대 방향의 잔류 응력이나 차수 세기의 어긋남에서 온다.

불확도는 $N$을 읽는 정밀도가 지배한다. 무늬 하나를 $\pm0.2$ 차수로 읽는다면 $N = 2$에서 상대 오차가 $10\,\%$나 된다. 이를 절반으로 줄이는 가장 쉬운 방법은 하중을 키워 더 높은 차수에서 읽는 것이다. 같은 $\pm0.2$라도 $N = 6$에서는 $3\,\%$가 된다. 자료점을 늘려 최소제곱으로 기울기를 구하는 것도 같은 효과를 낸다.

#### MARKING SCHEME:

::: marking
| 절편 $=$ 잔류·클램프 응력(추걸이 무게 누락은 양의 절편) | 0.2 |
| $N$의 읽기 오차가 지배함을 정량으로 제시 | 0.2 |
| 높은 차수에서 읽기 / 자료점 늘리기 등 구체적 개선안 | 0.2 |
:::

## Part C - 보 속의 응력 지도 (2.9점)

::: small
실라버스 역학(굽힘 모멘트, 응력 분포)과 그래프 분석. 굽힘 응력식 $\sigma = My/I$는 본문에서 주었다 [2].
:::

::: q C.1 1.0pt
깊이에 따른 무늬 위치.
:::

#### SOLUTION:

외팔보의 한 단면에서 무늬는 중립축을 가운데 두고 위아래로 대칭인 가로줄로 나타난다. $I = th^3/12 = 6.00\times10^{-3}\times(0.0250)^3/12 = 7.81\times10^{-9}\,\mathrm{m^4}$이고, $100\,\mathrm{g}$을 팔 길이 $60\,\mathrm{mm}$에 걸면 $M = 0.981\times0.060 = 5.9\times10^{-2}\,\mathrm{N\,m}$, 표면 응력은 $\sigma_{\max} = M(h/2)/I = 9.4\times10^{4}\,\mathrm{Pa}$, 표면 차수는 $N_{\max} = \sigma_{\max}t/f_\sigma = 2.8$이다. 곧 표면 근처에서 2–3개의 줄이 보인다.

#### MARKING SCHEME:

::: marking
| 한 단면을 정해 무늬 위치 $y_N$을 표로 기록 | 0.4 |
| 중립축 위아래 대칭을 확인, 양쪽 모두 측정 | 0.3 |
| $y_N$의 불확도를 적음 | 0.3 |
:::

::: q C.2 1.0pt
선형 분포와 중립축.
:::

#### SOLUTION:

$\sigma = My/I$이므로 $N = \sigma t/f_\sigma \propto y$이고, $N$ 대 $y_N$ 그래프는 원점을 지나는 직선이 되어야 한다. 직선을 외삽하여 $N = 0$이 되는 위치가 실험으로 정한 중립축이다. 균질한 직사각 단면에서는 기하학적 중심과 같아야 하며, 실제 측정에서도 $h/2$에서 $1\,\mathrm{mm}$ 안쪽으로 일치한다. 벗어난다면 시편이 기울어 물렸거나 축 방향 하중이 함께 걸린 것이다.

#### MARKING SCHEME:

::: marking
| $N$–$y_N$ 그래프가 직선임을 보임 | 0.4 |
| 외삽으로 중립축 결정, 기하학적 중심과 $\pm1\,\mathrm{mm}$ 이내 일치 | 0.4 |
| 어긋남의 원인(기울어진 물림, 축 하중)을 지적 | 0.2 |
:::

::: q C.3 0.9pt
굽힘으로 다시 구한 $f_\sigma$.
:::

#### SOLUTION:

기울기 $dN/dy = Mt/(I f_\sigma)$이므로

$$f_\sigma = \frac{Mt}{I\,(dN/dy)}.$$

$dN/dy = 2.8/0.0125 = 224\,\mathrm{m^{-1}}$이면

$$f_\sigma = \frac{5.9\times10^{-2}\times6.00\times10^{-3}}{7.81\times10^{-9}\times224} = 2.0\times10^{2}\,\mathrm{N\,m^{-1}}$$

로 B.2와 일치한다.

두 값이 어긋날 경우 **인장 쪽(B.2)을 더 믿어야 한다**. 인장에서는 응력이 시편 전체에 균일하고 $\sigma_1 - \sigma_2 = F/A$가 정확하지만, 굽힘에서는 (i) 고정단 근처의 응력 집중, (ii) 팔 길이와 하중 작용점의 불확실성, (iii) 큰 처짐에 따른 모멘트 변화가 모두 계통 오차로 들어오기 때문이다.

#### MARKING SCHEME:

::: marking
| $f_\sigma = Mt/[I(dN/dy)]$ 유도 | 0.3 |
| $f_\sigma = 2.0\times10^{2}\,\mathrm{N\,m^{-1}}$ ($1.4$–$2.8\times10^{2}$) | 0.3 |
| 인장 쪽이 더 신뢰할 만함을 구체적 근거와 함께 판정 | 0.3 |
:::

## Part D - 구멍은 응력을 얼마나 키우는가 (3.0점)

::: small
실라버스 역학(응력 집중)과 실험 설계. 무한판의 $K_t = 3$은 본문에서 주었다 [3, 4].
:::

::: q D.1 1.2pt
$K_t$ 측정의 설계와 실행.
:::

#### SOLUTION:

좋은 설계에는 다음이 들어 있어야 한다.

**하중 선택.** 먼 곳의 차수가 3 부근이 되도록 잡으면 구멍 가장자리에서는 10 부근이 되어 양쪽 모두 정밀하게 읽을 수 있다. $2.0\,\mathrm{kg}$이면 $\sigma_\infty = F/(b_2 t) = 19.6/(1.80\times10^{-4}) = 0.109\,\mathrm{MPa}$, $N_\infty = \sigma_\infty t/f_\sigma = 3.3$이다.

**먼 곳의 정의.** 하중 축 위에서 구멍의 영향은 구멍 지름의 3배 떨어진 곳에서도 아직 $8\,\%$이고 6배쯤에서 $2\,\%$로 줄어들므로, 구멍 중심에서 축 방향으로 $\geq 6d = 36\,\mathrm{mm}$ 떨어진 곳에서 읽는다. 시편 끝의 물림부는 피해야 한다.

**구멍 가장자리의 어려움.** 가장자리에서는 무늬가 촘촘하여 개수를 놓치기 쉽다. 하중을 0에서 천천히 올리며 구멍 옆 한 점을 지나가는 줄의 개수를 세는 방법이 가장 확실하다. 또한 구멍 가공면이 거칠면 국소적으로 거짓 무늬가 생기므로, 가장자리에 바로 붙은 점이 아니라 바깥으로 $1\,\mathrm{mm}$ 떨어진 점들에서 읽어 가장자리로 외삽하는 편이 낫다.

#### MARKING SCHEME:

::: marking
| 먼 곳 차수가 3 부근이 되도록 하중을 고른 근거 | 0.3 |
| 「먼 곳」을 $\geq 6d$로 정량 정의 | 0.3 |
| 하중을 올리며 세기 등 가장자리 차수 판독 방법 | 0.3 |
| $N_\infty$와 $N_{\text{edge}}$ 측정값을 불확도와 함께 제시 | 0.3 |
:::

::: q D.2 0.9pt
$K_t$의 값.
:::

#### SOLUTION:

같은 시편이므로 $t$와 $f_\sigma$가 지워지고 차수의 비가 곧 응력의 비이다.

$$K_t = \frac{N_{\text{edge}}}{N_\infty} = \frac{9.4}{3.3} = 2.9,$$

$$\frac{\delta K_t}{K_t} = \sqrt{\left(\frac{\delta N_{\text{edge}}}{N_{\text{edge}}}\right)^2 + \left(\frac{\delta N_\infty}{N_\infty}\right)^2} \approx 6\,\% \qquad (\delta N = \pm0.2\ \text{기준}),$$

곧 $K_t = 2.9 \pm 0.2$이다. $f_\sigma$의 불확도가 상쇄되어 들어오지 않는다는 점이 이 측정의 장점이다.

#### MARKING SCHEME:

::: marking
| $K_t = N_{\text{edge}}/N_\infty$, $t$와 $f_\sigma$가 상쇄됨을 지적 | 0.3 |
| $K_t = 2.9$ ($2.4$–$3.4$) | 0.3 |
| $\delta K_t$ 산출 | 0.3 |
:::

::: q D.3 0.9pt
유한 폭의 영향.
:::

#### SOLUTION:

구멍이 있으면 하중은 남은 폭 $b_2 - d$를 지나야 하므로, 먼 곳의 응력을 기준으로 잰 $K_t$에는 단면 감소 효과가 함께 들어온다. 여기서 $b_2/d = 5.0$이므로 순단면 응력은

$$\sigma_{\text{net}} = \frac{F}{(b_2 - d)\,t} = \frac{b_2}{b_2 - d}\,\sigma_\infty = 1.25\,\sigma_\infty$$

로 이미 $25\,\%$ 크다. 곧 **유한 폭은 $K_t$를 크게 만든다**. Peterson [3]에 실린 Howland의 해로는 $d/b_2 = 0.2$에서 순단면 응력 기준 $2.51$, 먼 곳 응력 기준 $3.14$이다. 측정값 $2.9$는 이보다 작으므로 무늬가 촘촘한 가장자리에서 차수를 한 개쯤 덜 센 것이다.

하중을 0부터 천천히 올리며 가장자리 한 점을 지나는 줄을 세어 그 점의 차수를 다시 읽어야 한다($N_\infty = 3.3$이면 $10.3$ 안팎). 그 밖의 원인으로는 구멍 가공면의 거칠기와 잔류 응력, 두께 방향의 응력 불균일이 있다.

#### MARKING SCHEME:

::: marking
| $\sigma_{\text{net}}/\sigma_\infty = b_2/(b_2 - d) = 1.25$ | 0.3 |
| $K_t \approx 3.14$로 커짐, $2.9$는 가장자리 차수를 덜 센 결과 | 0.3 |
| 남은 차이의 원인을 하나 이상 제시 | 0.3 |
:::
