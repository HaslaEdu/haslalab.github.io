# USAPhO 한국어판 양식 복원

사용자 Google Drive의 번역본에서 **USAPhO 준결승 시험**을 원본 문제지와 대조했다. 원본의 페이지 크기, 머리말·로고·쪽 번호·저작권 표시 및 문제별 배치 영역을 사용하고, 한국어 본문·수식·그림은 기존 번역 PDF의 벡터 내용을 옮긴다. 번역본 전체를 새 이름으로 복사하는 방식이 아니다.

- `tools/usapho_restore_sources.json`: 1997~2026년 원문 URL, 원문과 Drive 번역본의 입력 경로.
- `tools/usapho_restore.py`: 문제 번호와 문단·그림 경계를 대조하여 원문 페이지에 배치한다. 삽입한 안내문은 실제 글꼴의 렌더링 경계를 측정하여 참고표와 겹치지 않게 한다.
- `tools/usapho_scan_positions.json`: 텍스트 층이 없는 옛 원문 스캔의 위치 자료. 내용 번역에 OCR을 사용하지 않는다. `tools/usapho_ocr.py`로 위치 자료를 다시 추출할 수 있다(RapidOCR 필요).
- `tools/usapho_source_additions.json`: 1997~2006년 원문 목록을 기존 이론 목록에 추가할 자료.
- `tools/usapho_ko_additions.json`: 사이트 한국어판 연결 자료.
- `tools/usapho_validate.py`와 `tools/usapho_restore_report.json`: 페이지 수·크기, 원문 번호, 빈 페이지, 머리말 및 SHA-256 검증.

원문 PDF와 Drive에서 내려받은 번역 파일을 `usapho_restore_sources.json`의 경로에 둔 뒤 `python tools/usapho_restore.py`와 `python tools/usapho_validate.py`를 실행한다. 필요한 패키지는 PyMuPDF와 Pillow다. 특정 연도는 `--years 2021 2022`로 다시 만들 수 있다. 부분 재생성은 다른 연도의 연결 정보를 보존한다.

## 서로 다른 시험의 구분

- 2021년 Drive 파일의 1~9쪽은 USAPhO, 10~19쪽은 **USAPhO+ 대표 선발 시험**이다. 준결승에는 앞부분만 사용한다.
- 2022년 Drive 파일의 1~7쪽은 **훈련 캠프 이론 시험**, 8~13쪽은 실제 USAPhO A1~B3 번역이다. 뒤의 여섯 문제만 준결승 본문으로 사용하고, 실제 준결승 안내·참고표·부분 사이의 정지 페이지를 원문에 맞추어 복원한다.
- 2008년 미국광학회 Part C 보너스 문제를 보존한다.
- 1997년 마지막 압력 그래프와 2006년 마지막 세 그래프는 원문이 별도 전면 그래프 용지로 제공했다. 원문 그래프 페이지를 그대로 복원하고, 번역문 안의 중복 그래프는 본문에서 제외했다. 그래프의 영문 표기와 상수 참고표는 원본을 보존한다.
- Drive에 함께 있는 예선 문제지는 준결승 `T`에 섞지 않는다.

한국어 문장은 영문과 길이가 달라 본문은 문제별로 크기를 맞춘다. 그림을 가르지 않기 위해 한국어 내용이 한 원문 영역에 모두 들어가는 경우에는 그 영역을 사용한다. 남은 원문 페이지는 해당 해의 나머지 문항·페이지 구성을 유지한다. 자세한 크기 조정 값은 검증 보고서에 기록한다.
