운동이 등가속도 운동이므로, 평균 속력 $v_\mathrm{avg}$는 $v_\mathrm{f}$와 $v_0$으로 다음과 같이 나타낼 수 있다.

$v_\mathrm{avg} = \dfrac{L}{t} = \dfrac{v_0t + at^2/2}{t} = v_0 + \dfrac{v_\mathrm{f} - v_0}{2} = \dfrac{v_0 + v_\mathrm{f}}{2}.$

처음 속력과 나중 속력은 음수가 아니므로, 처음 속력에 대하여 다음 조건이 성립한다: $0 < v_0 < 2v_\mathrm{avg}$.

경로 한가운데에서의 속력 $v$를 $v_0$과 $v_\mathrm{avg}$로 나타내자.

$v^2 = 2v_\mathrm{avg}^2 - 2v_0v_\mathrm{avg} + v_0^2 = (v_\mathrm{avg} - v_0)^2 + v_\mathrm{avg}^2.$

최소 속력 $v_\mathrm{min}$은 $v_0 = v_\mathrm{avg}$일 때 얻어지며 $v_\mathrm{avg}$와 같다. 최대 속력 $v_\mathrm{max}$는 $v_0 = 0$ 또는 $v_0 = 2v_\mathrm{avg}$일 때 얻어지며 $\sqrt2\,v_\mathrm{avg}$와 같다.

문제 2. 발코니에서

물체의 운동 에너지의 변화율은 물체에 작용하는 힘들의 일률이다. 공에는 중력과 공기의 저항력이 작용한다. 조건에 따라 저항력은 속도에 비례한다.

$\vec F_\mathrm{r} = -\alpha\vec v.$

공에 작용하는 힘들의 일률의 합은 다음과 같다.

$N = (m\vec g + \vec F_\mathrm{r})\cdot\vec v = mgv - \alpha v^2,$

(3)

여기서 $v$는 공의 속도 $\vec v$를 연직 아래 방향의 축에 정사영한 성분이다.

떨어지는 동안 공은 저항력이 중력과 평형을 이룰 때까지 가속된다. 일정한 속력으로 움직일 때의 속력 $v_2$를 알고 있으므로, 연직 아래 방향의 축에 대하여 공의 뉴턴 제2법칙을 쓰고 가속도를 0으로 놓으면 계수 $\alpha$를 구할 수 있다.

$0 = mg - \alpha v_2,\quad\text{따라서}\quad\alpha = \dfrac{mg}{v_2}.$

운동하는 동안 $v$는 $-v_0$에서 $v_2$까지 변한다.

일률에 대한 식 (3)은 다음과 같이 바꾸어 쓸 수 있다.

그래프에서 알 수 있듯이, 운동 에너지 변화율의 (크기의) 최댓값은 $v = v_1$일 때 또는 $v = -v_0$일 때 얻어진다. 이때 일률은 첫 번째 경우에 $N_1 = \dfrac{(mg)^2}{4\alpha}$이고, 두 번째 경우에 $N_2 = \dfrac{(mg)^2}{4\alpha} - \alpha\left(v_0 + \dfrac{mg}{2\alpha}\right)^2$이다. $N_1$과 $N_2$를 비교하면, $v_0 < v_\mathrm{cr} = \dfrac{\left(\sqrt2 - 1\right)mg}{2\alpha}$일 때 $N_1 > N_2$이고 따라서 $v_\mathrm{max} = v_1$이며, $v_0 > v_\mathrm{cr}$일 때 $N_2 > N_1$이고 $v_\mathrm{max} = v_0$이다. $v_0 = v_\mathrm{cr}$일 때에는 두 답이 모두 맞다.

문제 3. 수중 작업

잠수종 안의 공기 부피의 변화를 계산하기 위하여 보일-마리오트 법칙을 이용하자. $pV = (p + \Delta p)(V - \Delta V)$이고, 이로부터 공기의 부피는 다음만큼 줄어든다.

$\Delta V = V\left(\dfrac{\Delta p}{p + \Delta p}\right) = 0.0133\,\mathrm{m^3}.$

«잠수종 + 추 + 잠수종 안의 물기둥»으로 이루어진 계의 평형을 생각하자. 이 계에는 다음과 같은 외력이 작용한다: 중력, 케이블의 장력 $F_1$, 그리고 계의 윗면과 아랫면에 작용하는 정수압에 의한 힘(그림 14에 모든 힘이 나타나 있지는 않다). 추를 들어 올리면 공기의 부피가 줄어들고, 비게 된 부피 $\Delta V$는 질량 $\rho\Delta V$인 물이 차지한다. 이때 계에 작용하는 모든 외력 가운데 케이블의 장력과 잠수종 안의 물에 작용하는 중력만 바뀐다. 따라서 케이블의 장력은 다음만큼 줄어든다.

$\Delta F = \rho\Delta Vg = 133\,\mathrm{N}.$

문제 5. 컴퓨터가 달린 전원

1) 전원을 통해 흐른 전하량이 시간에 따라 어떻게 변하는지 얻기 위하여, 문제에서 주어진 평균 전류의 정의를 이용하자.

$I_\mathrm{avg} = \dfrac{q}{t} \Rightarrow q = I_\mathrm{avg}t$

시간 $t$ 동안 전원을 통해 흐른 전하량은 수치상으로 직사각형의 넓이 $q = I_\mathrm{avg}t$와 같다. 여러 점(15개 이상)에 대하여 흐른 전하량을 구하여 $q(t)$ 그래프를 그린다(그림 16).

2) 구간 OA는 직선이므로, 시각 $t_\mathrm{A}$에서의 전류는 다음과 같이 구할 수도 있다.

$I_\mathrm{avg} = \dfrac{q}{t} = \alpha t \to q = \alpha t^2$

$I = \dfrac{\Delta q}{\Delta t} = \alpha\dfrac{(t + \Delta t)^2 - t^2}{\Delta t} \approx \alpha\dfrac{2t\Delta t}{\Delta t} = 2\alpha t = 2I_\mathrm{avg}t$

점 $A$에 대하여: $I_A = 2t_A\cdot I_\mathrm{avg}(t_A) = 6\,\mathrm{mA}$

저항기의 저항 $R$은 줄-렌츠 법칙으로부터 구한다.

$R = \dfrac{N_A}{I_A^2} = 4.44\,\mathrm{k\Omega}$

3) 최대 전류에는 $q(t)$ 그래프에서 기울기가 가장 큰 점 $B$가 대응한다(여기서는 변곡점).
