문제 1. 상대성 이론

그림 16

입자 중 하나(예를 들어 첫 번째 입자)에 고정된 기준계로 옮겨 가자. 속도와 가속도의 합성 법칙을 이용한다. 두 입자의 속도는 (가속도와 마찬가지로) 늘 서로 수직이므로 피타고라스 정리를 쓸 수 있다. 그 결과 두 번째 입자는 속력 $5v$와 가속도 $5a$로 운동을 시작한다(그림 16). 두 번째 입자가 원래 OX축을 따라 움직였다고 하자. 새 기준계에서 OX축과 처음 속도(및 처음 가속도) 사이의 각 $\alpha$는 원래 기준계에서 입자들의 속도(및 가속도)가 서로 수직이라는 조건으로부터 구한다. $\mathrm{tg}\,\alpha = 3/4$, $\alpha = 36.87^\circ$. 수직선과 $2\alpha$의 각을 이루며 던진 물체의 도달 거리 문제와 같은 방법으로 다음을 얻는다.

$L = \dfrac{(5v)^2\sin 4\alpha}{5a} = \dfrac{5v^2\sin 4\alpha}{a} = 500\,\mathrm{m}.$

상대 속력은 속도 벡터가 가속도 벡터와 수직이 되는 순간 최소가 된다. 따라서 $v_{\mathrm{rel}(\min)} = 5v\sin 2\alpha = 48\,\mathrm{m/s}$이다.

문제 2. 관이 문제다!

첫 번째 경우에 물기둥의 길이를 $L_\mathrm{w}$, 얼음 기둥의 길이를 $L_\mathrm{i}$라고 하자. 그러면

$L_\mathrm{w} + L_\mathrm{i} = L_2.$

(1)

피스톤 사이에 든 물질의 질량은 일정하므로

$L_\mathrm{w}\rho_\mathrm{w} + L_\mathrm{i}\rho_\mathrm{i} = L_1\rho_\mathrm{w}.$

(2)

얼음과 물을 지나는 열의 흐름이 같으므로

$\dfrac{kS(t_2 - t_0)}{L_\mathrm{w}} = \dfrac{4kS(t_0 - t_1)}{L_\mathrm{i}},\quad\text{여기서}\quad t_0 = 0\,{}^\circ\mathrm{C}.$

(3)

주어진 온도를 고려하면 식 (3)으로부터 $L_\mathrm{i} = 10L_\mathrm{w}$임을 얻는다. 식 (1)과 (2)로부터 $L_\mathrm{w} = 8\,\mathrm{cm}$, $L_2 = 11L_\mathrm{w} = 88\,\mathrm{cm}$를 얻는다.

모든 단면을 지나는 열의 흐름 $P$는 같다.

결선. 이론 시험

여기서 $t'_1$, $t'_2$는 길이 $\Delta L$인 원통 조각의 왼쪽과 오른쪽의 온도이다. 따라서 $t'_2 - t'_1 = (P\Delta L)/(kS)$, 즉 $\Delta t \sim \Delta L$이다. 이는 피스톤에서 경계면까지 얼음과 물의 온도가 선형으로 변한다는 뜻이므로, 계의 각 부분이 평균 온도(얼음 $t_\mathrm{i} = -20\,{}^\circ\mathrm{C}$, 물 $t_\mathrm{w} = 8\,{}^\circ\mathrm{C}$)를 가진다고 볼 수 있다. 계를 단열한 뒤에는 피스톤 사이에서 어떤 온도 $t$로 열평형이 이루어진다. 물이 녹는점까지 식으면서 방출하는 열량은 다음과 같다.

$Q_1 = L_\mathrm{w}S\rho_\mathrm{w}c_\mathrm{w}t_\mathrm{w} = 33\,600\,L_\mathrm{w}S\rho_\mathrm{w}.$

얼음을 녹는점까지 데우는 데 필요한 열량은 다음과 같다.

$Q_2 = 10L_\mathrm{w}S\,0.9\rho_\mathrm{w}c_\mathrm{i}(0 - t_\mathrm{i}) = 378\,000\,L_\mathrm{w}S\rho_\mathrm{w}.$

따라서 물은 확실히 $0\,{}^\circ\mathrm{C}$까지 식고 얼기 시작한다. 물이 얼 때 방출하는 열량은 다음과 같다.

$Q_3 = \lambda L_\mathrm{w}S\rho_\mathrm{w} = 330\,000\,L_\mathrm{w}S\rho_\mathrm{w}.$

이 열은 얼음을 녹는점까지 데우기에 부족하다. 따라서 물이 모두 언다. 그러면

$L_3 = \dfrac{10}{9}L_1 \approx 88.9\,\mathrm{cm}.$

문제 3. 고리 위의 구슬

계가 대칭이므로 구슬이 움직이는 동안 고리는 수평 방향으로 움직이지 않는다. 고리가 수평면에서 떨어지려면 $N_1 = 0$이어야 한다(그림 17). 이는 구슬이 고리에 작용하는 반작용력 $N$이 중심에서 바깥쪽을 향할 때 가능하다. 이 순간까지 각 구슬은 연직선에서 각 $\alpha$만큼 벗어난다(그림 18). 그러면 뉴턴의 제2법칙에 따라 각 구슬에 대하여 다음 관계가 성립한다.

여기서 $N$은 고리가 구슬에 작용하는 힘이다.

결선. 이론 시험

계(얼음, 물, 도르래, 실)의 질량이 변하지 않는다는 점을 고려하여, 내용물이 컵 바닥에 작용하는 힘을 두 가지 방법으로 구하자.

1.  내용물의 평형 조건으로 구한, 바닥이 내용물에 작용하는 힘의 반작용(뉴턴의 제3법칙)으로 구하면

$8T + F_\text{바닥} = m_\text{계}g,$

식 (4)를 고려하면 다음과 같다.

$8mg + F_\text{바닥} = m_\text{계}g.$

그림 19

2.  내용물이 바닥에 작용하는 실제 힘들의 합으로 구하면

$F_\text{바닥} = \rho ghS,$

여기서 $F_\text{바닥}$은 정수압에 의한 힘이다(바닥에 닿아 있는 것은 없다). 얼음 조각에 열량 $Q$를 공급하면 그 질량이 $\Delta m = Q/\lambda$만큼 줄어든다. 바닥에 작용하는 새로운 힘에 대한 식은 다음과 같다.

$8(m - \Delta m)g + F^*_\text{바닥} = m_\text{계}g,$

$F^*_\text{바닥} = \rho gS(h + \Delta h_1).$

내용물 전체의 질량에 대하여 두 식을 같게 놓으면 다음을 얻는다.

즉 $\rho gS\Delta h_1 = 8Q/\lambda$이므로 컵 바닥의 넓이는 다음과 같다.

$S = \dfrac{8Q}{\Delta h_1\rho\lambda} = 20\,\mathrm{cm^2}.$

$\Delta h_1$의 부호가 양이므로 수면이 높아진다는 것에 주목하자. 식 (5)로부터 매달린 얼음 조각의 질량이 줄어듦에 따라 수면의 높이가 선형으로 높아짐을 알 수 있다. 얼음 조각이 완전히 녹은 뒤 바닥에 작용하는 힘에 대한 연립 방정식은 다음과 같다.

$F^{**}_\text{바닥} = m_\text{계}g,$

$F^{**}_\text{바닥} = \rho gS(h + \Delta h_2).$

따라서 $\rho S\Delta h_2 = 8m$이고, $6m$에 연결된 실의 장력이 변하는 범위는 $0 < T < \rho gS\Delta h_2/4$, 즉 $0 < T < 0.15\,\mathrm{N}$이다.

1.  그래프로부터 $x = 0.2\,\mathrm{m}$일 때 전류계에 전류가 흐르지 않음을 알 수 있다. 단면적이 일정한 균일한 도체의 저항은 길이에 비례하므로 저항의 비는 $r_1 : r_2 = 1 : 4$이다(그림 20). 이때 저항 $R_1$과 $R_2$에 흐르는 전류가 같으므로, $R_1$과 $R_2$에 걸린 전압 $U_1$과 $U_2$의 비는 $U_1 : U_2 = R_1 : R_2$이다. 마찬가지로 저항 $r_1$과 $r_2$에 흐르는 전류가 같으므로 $U_1 : U_2 =$ $r_1 : r_2$이다. 따라서

2.  병렬로 연결된 저항 $R_1$과 $r_1$의 합성 저항은 $r_1$을 넘지 않고, 병렬로 연결된 저항 $R_2$와 $r_2$의 합성 저항은 $r_2$를 넘지 않는다. 따라서 네 저항 $R_1$, $r_1$, $R_2$, $r_2$로 이루어진 회로의 저항은 $r_1 + r_2 = 1\,\mathrm{k\Omega}$보다 클 수 없다. 그러므로 저항 $R_3$까지 고려한 전체 회로의 저항은 $1\,\mathrm{M\Omega}$에서 $1.001\,\mathrm{M\Omega}$ 사이에 있다.

3.  전류계가 위치 1에 있고 전류계에 전류 $I_1 = |I_A| = 2\,\mu\mathrm{A}$가 흐를 때, 가변 저항기 $r$에 걸린 전압은 $(I_0 - I_1)r$이고, 저항 $R_2$에 걸린 전압은 $I_1R_2$이다. 따라서 $(I_0 - I_1)r =$ $I_1R_2$이다.

전류계가 위치 2에 있고 전류계에 전류 $I_2 = |I_A| = 3\,\mu\mathrm{A}$가 흐를 때, 가변 저항기 $r$에 걸린 전압은 $(I_0 - I_2)r$이고, 저항 $R_1$에 걸린 전압은 $I_2R_1$이다. 따라서 $(I_0 - I_2)r =$ $I_2R_1$이다.
