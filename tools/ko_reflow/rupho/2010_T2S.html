문제 1. 판 위에서 미끄러지는 물체

1. 실의 장력을 $T$라고 하자. 세 물체 각각에 대하여 뉴턴의 제2법칙을 쓰면 다음과 같다.

$m_1a_1 = T - F_\mathrm{fr},\qquad m_2a_2 = F_\mathrm{fr},\qquad Ma_1 = Mg - T.$

여기서 $a_1$과 $a_2$는 각각 물체와 판의 가속도이다. 이 식들로부터 다음을 얻는다.

$a_1 = \dfrac{Mg - F_\mathrm{fr}}{m_1 + M},\qquad a_2 = \dfrac{F_\mathrm{fr}}{m_2}.$

미끄러지지 않고 움직일 때는 $a_1 = a_2$이다.

$\dfrac{Mg - F_\mathrm{fr}}{m_1 + M} = \dfrac{F_\mathrm{fr}}{m_2},\qquad\text{따라서}\qquad F_\mathrm{fr} = \dfrac{Mm_2}{m_1 + m_2 + M}\,g.$

이때 마찰력의 크기는 $\mu m_1g$를 넘을 수 없다. 따라서 미끄러지지 않고 움직이려면 다음 조건이 필요하다.

$F_\mathrm{fr} = \dfrac{Mm_2}{m_1 + m_2 + M}\,g \leqslant \mu m_1g,\qquad\text{따라서}\qquad \mu_\mathrm{min} = \dfrac{Mm_2}{m_1(m_1 + m_2 + M)}.$

2. 모든 물체의 질량의 수치를 대입하면 다음을 얻는다.

$\mu \geqslant \mu_\mathrm{min}$이면 미끄러짐이 없고, $\mu < \mu_\mathrm{min}$이면 물체가 판 위에서 미끄러진다.

3. 이제 $\mu = \mu_\mathrm{min}/2 = 1/4$이라고 하자. 그러면 다음과 같다.

상대 가속도는 다음과 같다.

$a_\mathrm{rel} = a_1 - a_2 = g\left(\dfrac{M - m_1\mu}{m_1 + M} - \dfrac{m_1}{m_2}\mu\right) = g/4.$

미끄러져 떨어지는 시간은 식 $L = a_\mathrm{rel}t^2/2$로부터 구한다.

$t = \sqrt{\dfrac{2L}{a_\mathrm{rel}}} = 0.9\,\mathrm{s}.$
