3단계 - 3학년 시험

1) 여기에 나온 식들은 수식 편집기의 도움 없이 입력하였다. 그래서 본문에서는, 예를 들어 $R$의 역수를 $1/R$ 또는 $R^{-1}$로, $p$의 제곱근을 $\sqrt{p}$ 또는 $(p)^{1/2}$로 쓰는 등 여러 표기를 함께 썼다.

2) 여기에 제시한 풀이는 참고용이며 유일한 풀이가 아니다. 채점할 때에는 학생이 전개한 추론을 고려하였으며, 그 전개 과정이 여기에 제시한 풀이와 늘 같지는 않았다.

문제 01 - 3학년 (6.0점)

주어진 상황은 흡열 기체 과정을 다룬다. 등압 과정, 이어서 등적 과정, 마지막으로 다시 등압 과정으로 이루어져 있다.

a)

I) $T_1$의 계산 (등압 과정, $0 \rightarrow 1$)

$V_0/T_0 = V_1/T_1 \;\rightarrow\; S{\cdot} a/T_0 = S{\cdot}(a+b)/T_1 \;\therefore\; T_1 = S{\cdot}(a+b){\cdot} T_0/S{\cdot} a$

$T_1 = (0.6+0.2){\cdot}300/0.6 \qquad\rightarrow\qquad \boldsymbol{T_1 = 400}\,\mathbf{K}$

II) $Q_1$의 계산 (등압 과정, $0 \rightarrow 1$)

$\gamma = c_p/c_v \qquad c_p = 1.664{\cdot}3125 \qquad c_p = 5200\ \mathrm{J/kg{\cdot}K}$

$Q_1 = m{\cdot} c_p{\cdot}(T_1 - T_0) \;\;\rightarrow\;\; Q_1 = 4{\cdot}10^{-3}{\cdot}5200{\cdot}(400-300) \;\;\rightarrow\;\; \boldsymbol{Q_1 = 2080}\,\mathbf{J}$

b)

III) $T_2$의 계산 (등적 과정, $1 \rightarrow 2$)

$P_1/T_1 = p_2/T_2 \;\;\therefore\;\; T_2 = (p_{atm} + (P_E + P_F)/S)\,/\,(p_{atm} + P_E/S){\cdot} T_1 \quad\rightarrow$

$T_2 = (1{\cdot}10^5 + (300{\cdot}10 + 100{\cdot}10)/100{\cdot}10^{-4})/(1{\cdot}10^5 + 300{\cdot}10/100{\cdot}10^{-4}){\cdot}400 \;\;\rightarrow\;\; \boldsymbol{T_2 = 500}\,\mathbf{K}$

IV) $Q_2$의 계산 (등적 과정, $1 \rightarrow 2$)

$Q_2 = m{\cdot} c_v{\cdot}(T_2 - T_1) \;\;\rightarrow\;\; Q_2 = 4{\cdot}10^{-3}{\cdot}3125{\cdot}(500-400) \;\;\rightarrow\;\; \boldsymbol{Q_2 = 1250}\,\mathbf{J}$

V) $T_3$의 계산 (등압 과정, $2 \rightarrow 3$)

$V_2/T_2 = V_3/T_3 \;\;\rightarrow\;\; S{\cdot}(a+b)/T_2 = S{\cdot}(a+2{\cdot} b)/T_3 \;\;\therefore\;\; T_3 = (0.6+2{\cdot}0.2){\cdot}500/(0.6{\cdot}0.2) \quad\rightarrow$

$\boldsymbol{T_3 = 625}\,\mathbf{K}$

VI) $Q_3$의 계산 (등압 과정, $2 \rightarrow 3$)

$Q_3 = m{\cdot} c_p{\cdot}(T_3 - T_2) \;\;\rightarrow\;\; Q_3 = 4{\cdot}10^{-3}{\cdot}5200{\cdot}(625-400) \;\;\rightarrow\;\; \boldsymbol{Q_3 = 2600}\,\mathbf{J}$

VII) 저항기를 켜 두는 시간 $\Delta t$의 계산. (저항기는 모든 전기 에너지를 열로 바꾸고, 이 열은 모두 기체에 흡수된다.)

$Q_{total} = P_{\text{전기}}{\cdot}\Delta t \;\;\rightarrow\;\; Q_{total} = V^2{\cdot}\Delta t/R \;\;\rightarrow\;\; Q_1 + Q_2 + Q_3 = 110^2{\cdot}\Delta t/1210$

$2080 + 1250 + 2600 = 110^2{\cdot}\Delta t/12 \;\;\therefore\;\; \boldsymbol{\Delta t = 593}\,\mathbf{s}$

c)

VIII) 효율 $\eta$의 계산

$\eta =$ 한 일/소비한 에너지   $\eta = [p_0{\cdot}(V_1 - V_0) + p_2{\cdot}(V_3 - V_2)]/Q_{total} \quad\rightarrow$

문제 03 - 3학년 (6.0점)

이 현상을 이해하려면 완전 유도에 대한 지식이 필요하다. 안쪽 도체는 $1\ \mu\mathrm{C}$의 양전하를 띠고, 이를 둘러싼 중성 도체는 완전 유도에 의해 안쪽 면에 $1\ \mu\mathrm{C}$의 음전하, 바깥쪽 면에 $1\ \mu\mathrm{C}$의 양전하를 띠게 된다. 두 도체 사이와 바깥쪽의 전기장은 바깥으로 퍼져 나가는 지름 방향의 전기장이며, 그 세기는 거리의 제곱에 반비례하여 변한다. $r = 50\ \mathrm{cm}$에서 그래프가 불연속인 것은 바로 그 위치에 바깥쪽 도체가 있기 때문이다.

a)

I) $r = 20\ \mathrm{cm}$에서 전기장 세기의 계산

$E_{20} = (1/4\pi\varepsilon_o){\cdot} Q/r^2 \;\;\rightarrow\;\; E_{20} = 9{\cdot}10^9{\cdot}1{\cdot}10^{-6}/(20{\cdot}10^{-2})^2 \;\;\rightarrow\;\; E_{20} = 225\ \mathrm{kV/m}$

II) 입자에 작용하는 힘의 계산

$F_{20} = E_{20}{\cdot} q \quad\rightarrow \boldsymbol{F_{20} = 2.25{\cdot}10^{-4}}\,\mathbf{N}$

b)

III) 안쪽 도체 표면에서 전기장의 전위 계산

$V_A = (1/4\pi\varepsilon_o){\cdot} Q/r_A \;\;\rightarrow\;\; V_A = 9{\cdot}10^9{\cdot}1{\cdot}10^{-6}/10{\cdot}10^{-2} \;\;\rightarrow\;\; \boldsymbol{V_A = 90000}\,\mathbf{V}$

IV) 전체 계의 중심에서 100 cm 떨어진 점에서 전위의 계산

$V_B = (1/4\pi\varepsilon_o){\cdot} Q/r_B \;\;\rightarrow\;\; V_A = 9{\cdot}10^9{\cdot}1{\cdot}10^{-6}/100{\cdot}10^{-2} \;\;\rightarrow\;\; \boldsymbol{V_A = 9000}\,\mathbf{V}$

V) 입자의 속력 계산

$\tau = V_{AB}{\cdot} q$ 그런데 $\tau = \Delta E_C \;\rightarrow\; (V_A{-}V_B){\cdot} q = (m{\cdot} v_B^2)/2 - (m{\cdot} v_A^2)/2 \,\therefore\, v_B = [2{\cdot}(V_A - V_B){\cdot} q/m]^{1/2}$

$v_B = [2{\cdot}(90000 - 9000){\cdot}1{\cdot}10^{-9}/2{\cdot}10^{-10}]^{1/2} \;\;\rightarrow\;\; \boldsymbol{v_B = 900}\,\mathbf{m/s}$

문제 04 - 3학년 (6.0점)

주어진 상황을 풀려면 여러 운동체 사이의 상대 운동에 대한 지식이 필요하다. 도플러-피조 효과와 관련된 식을 이 경우에 맞게 고쳐 쓰는 방법도 이 문제의 풀이로 인정하였다.

a)

I) 운동 방정식으로부터 발사체가 전투기 B에 이르는 데 걸리는 시간의 계산

발사체

$x_P = x_{0P} + v_P{\cdot} t \;\;\rightarrow\;\; x_P = 0 + 600{\cdot} t$

전투기 B

$x_B = x_{0B} + v_B{\cdot} t \;\;\rightarrow\;\; x_P = 600 + 120{\cdot} t$

둘이 만나는 조건은  $x_P = x_B \qquad 600{\cdot} t = 600 + 120{\cdot} t \;\;\therefore\;\; \boldsymbol{t = 1.25}\,\mathbf{s}$

b)

II) 연이은 발사체 사이의 거리 계산

발사원이 정지해 있다면, $0.25\ \mathrm{s}$ 동안 발사체들은 $d = v_P{\cdot} t$, 즉 $d = 150\ \mathrm{m}$만큼 떨어져 있을 것이다.

그러나 $0.25\ \mathrm{s}$ 동안 발사원(전투기 A)과, 따라서 다음 발사체도 $\Delta d = v_A{\cdot}0.25$, 즉

$\Delta d = 100{\cdot}0.25 \;\;\rightarrow\;\; \Delta d = 25\ \mathrm{m}$만큼 움직인다.

따라서 연이은 발사체 사이의 거리는 $d' = d - \Delta d$, 즉 $\boldsymbol{d' = 125}\,\mathbf{m}$이다.

c)

III) 발사체가 전투기 B에 맞는 진동수의 계산

전투기 B에 대한 발사체의 상대 속도는 다음과 같다.

$v_{P/B} = v_P - v_B = 600 - 120 \qquad\rightarrow\qquad v_{P/B} = 480\ \mathrm{m/s}$

발사체들은 서로 $125\ \mathrm{m}$씩 떨어져 있으므로, 이들이 전투기 B에 잇달아 부딪치는 시간 간격은 다음과 같다.

$d' = v_{P/B}{\cdot}\Delta t \;\;\rightarrow\;\; 125 = 480{\cdot}\Delta t \;\;\therefore\;\; \Delta t = 125/480$  또는  $\Delta t = 25/96$초(발사체 한 개마다).

이는 $25\ \mathrm{s}$마다 발사체 96개, 곧 1초에 발사체 3.84개라는 뜻이기도 하다.

이 문제는 두 가지 상황을 다루며, 둘 다 임계 상황이다.

I) 첫째는 트럭이 커브를 돌 때 짐이 미끄러지기 직전인 상황이다(그림은 이 상황을 나타낸다). 짐이 미끄러지기 시작하면 안 되므로 다음이 성립한다.

a)

$\rightarrow$ 연직축: (연직 방향의 평형)

$N{\cdot}\cos\alpha - F_A{\cdot}\sin\alpha - P = 0$    또는

$m{\cdot} g = N{\cdot}\cos\alpha - \mu{\cdot} N{\cdot}\sin\alpha \qquad (1)$

$\rightarrow$ 수평축: (구심력 ($F_C$)은 수평 방향의 알짜힘이다)

$F_C = N{\cdot}\sin\alpha + F_A{\cdot}\cos\alpha$    또는

$R = (20^2/10){\cdot}[12 - 0.18{\cdot}5]/[5 + 0.18{\cdot}12] \;\;\rightarrow\;\; \boldsymbol{R = 62.01}\,\mathbf{m}$

문제 07 - 3학년 (6.0점)

이 문제는 두 극단적 상황에서 물체의 안정성을 논의한다. 궤도의 가장 높은 점(그림 1)에서는

수직 항력 $N$이 0보다 큰 어떤 최솟값을 가지는 한 안정성이 유지된다. 학생은 이 점에서 가속도의 연직 성분만 있음을 알아야 한다. 따라서

a)

I) 연직 가속도 $a_{max1}$의 계산

$P - N = m{\cdot} a \;\;\rightarrow\;\; m{\cdot} g - N = m{\cdot} a \;\;\rightarrow\;\; m{\cdot} g - 0 = m{\cdot} a_{max1}$

II) 최대 각속도 $\omega_{max1}$의 계산

$m{\cdot} g = m{\cdot}\omega_{max1}^2{\cdot} R \;\;\therefore\;\; \boldsymbol{\omega_{max1} = \sqrt{(g/R)}}$

b)

중간 점(그림 2)에서 수평축을 따라 분석하면, 물체는 최대 변위, 최소 속도, 최대 가속도인 점에 있다. 따라서 정지 마찰력이 구심력의 역할을 온전히 할 수 있으면 안정성이 보장된다. 학생은 이 점에서 가속도의 수평 성분만 있음을 알아야 한다. 따라서

III) 속도, 연직 가속도 $a_{max2}$의 계산

$F_A = m{\cdot} a \;\;\rightarrow\;\; \mu{\cdot} m{\cdot} g = m{\cdot} a \;\;\rightarrow\;\; \mu{\cdot} m{\cdot} g = m{\cdot} a_{max2}$

IV) 최대 각속도 $\omega_{max2}$의 계산

$\mu{\cdot} m{\cdot} g = m{\cdot}\omega_{max2}^2{\cdot} R \;\;\therefore\;\; \boldsymbol{\omega_{max2} = \sqrt{(\mu{\cdot} g/R)}}$

문제 08 - 3학년 (6.0점)

이 문제는 갈릴레이의 운동 중첩 원리와 관련된 문제로, 대전 입자가 균일한 자기장 속에서 움직인다. 입자의 속도가 자기장선과 각을 이루므로, 학생은 두 운동이 겹쳐진 것으로 생각해야 한다. 하나는 알짜힘이 0인 상태에서의 연직 운동이고, 다른 하나는 속도에 수직인 힘을 받아 등속 원운동을 하는 수평 운동이다. 각 $\alpha$는 스크린에 수직인 연직면의 수평선에 대한 처음 속도의 방향을 정하고, 각 $\beta$는 수평면에서, 입자가 자기력을 받아 출발 위치에서 도착 위치까지 그리는 원호의 부채꼴을 정한다.

a)

I) 속도 성분의 계산

$v_x = v{\cdot}\cos\alpha \;\;\rightarrow\;\; v_x = 1300{\cdot}120/(120^2 + 50^2)^{1/2} \qquad\rightarrow\quad \boldsymbol{v_x = 1200}\,\mathbf{m/s}$

$v_y = v{\cdot}\sin\alpha \;\;\rightarrow\;\; v_x = 1300{\cdot}50/(120^2 + 50^2)^{1/2} \qquad\rightarrow\quad \boldsymbol{v_x = 500}\,\mathbf{m/s}$

II) 궤도를 수평면에 투영한 원의 반지름 계산

$R = m{\cdot} v_x/(B{\cdot} q) \;\;\rightarrow\;\; R = 1{\cdot}10^{-8}{\cdot}1200/(0.5{\cdot}10{\cdot}10^{-6}) \;\;\rightarrow\;\; \boldsymbol{R = 2.4}\,\mathbf{m}$

III) 충돌할 때까지 돈 각의 계산

$\sin\beta = x/R \;\;\rightarrow\;\; \sin\beta = 1.20/2.40 \;\;\rightarrow\;\; \sin\beta = 0.50 \;\;\therefore\;\; \boldsymbol{\beta = 30^\circ}$

IV) 원 궤도의 주기 $T$의 계산

$v_x = 2{\cdot}\pi{\cdot} R/T \;\;\rightarrow\;\; 1200 = 2{\cdot}3{\cdot}2.4/T \;\;\therefore\;\; \boldsymbol{T = 12{\cdot}10^{-3}}\,\mathbf{s}$

b)

V) 스크린에 이르는 데 걸리는 시간의 계산

$360^\circ/T = 30^\circ/\Delta t \;\;\therefore\;\; \boldsymbol{\Delta t = 1{\cdot}10^{-3}}\,\mathbf{s}$

VI) 충돌 지점 좌표의 계산

$x = R - R{\cdot}\cos\beta \;\;\rightarrow\;\; x = -2.4 - (-2.4{\cdot}0.87) \;\;\rightarrow\;\; \boldsymbol{x = -0.312}\,\mathbf{m}$

$y = v_y{\cdot}\Delta t \;\;\rightarrow\;\; y = 500{\cdot}1{\cdot}10^{-3} \;\;\rightarrow\;\; \boldsymbol{y = 0.50}\,\mathbf{m}$
